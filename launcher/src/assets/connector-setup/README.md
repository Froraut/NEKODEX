# Connector setup schematics

Original NEKODEX illustrations created on 2026-10-18. These are schematic
relationships, not representations of current OpenAI or ChatGPT screens. They
contain no account identifiers, credential values, provider logos or remote assets.
Labels and equivalent text instructions are supplied by connector-setup-help-copy.ts
in all six launcher languages; the artwork itself has no language-dependent text.
The CSS mask applies semantic theme tokens, including in the light theme.

Reviewed reference material: NEKODEX AccountToolsOnboarding/McpSurface and
`docs/design/screenshots/mcp-responsive.png`; the reviewed Chat On Steroids checkout
has actual setup images under `src/renderer/setup-images/pages` (not its absent
`docs/images/setup`). Its tunnel-create and API-key permission illustrations were
inspected, but no foreign artwork or text was copied. Those screenshots include
another product's identity and provider-specific controls, so this guide uses its
own schematic drawings and the existing NEKODEX account actions.

Maintain the manifest and localized instructions together when setup contracts
change. Never replace these with a private live account screenshot. Help must not
publish readiness, tool proof or a credential mutation.
