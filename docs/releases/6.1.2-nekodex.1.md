# NEKODEX 6.1.2-nekodex.1

This prerelease makes NEKODEX's Web models appear in the Codex app's model picker again and saves vertical space in the Browser screen.

## Changes

- **Web models in the Codex app picker.** The Codex desktop app now lists only models that OpenAI allows for the signed-in account, which hid NEKODEX's Web models even though Codex received them. In the default **Native and Web models** mode, NEKODEX now gives Codex its own model list. It contains your account's native models, the named Web models, and hidden entries so saved tasks with older Web model IDs keep working.
- NEKODEX keeps that list current from Codex's own traffic. Codex reads it when it starts, so fully quit and reopen Codex after a model change.
- The model list can be turned off under **Connections → Other clients → Codex provider** or with `codex-chatgpt-web provider picker-off`. The choice survives later setup runs. A `model_catalog_json` you configured yourself always takes precedence. Web-only mode, disconnecting and uninstalling restore your previous Codex settings exactly.
- Web-only setup no longer fails when setup has just cleared Codex's model cache; it uses NEKODEX's last copy of your native model list.
- The **Separate browser windows** summary now sits at the end of the task tab row instead of taking its own line. Its list opens on a full-width line below.
- The `codex --profile nekodex` installer and the development smoke checks use the named Web models.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

New integration tests cover the picker catalog: install, disconnect/reconnect, uninstall, opt-out persistence, Web-only switching, a user-owned catalog and runtime refresh. The existing Web-only, client-connection and model-capability tests, root and launcher TypeScript checks, the Codex catalog smoke and the architecture map also passed.

Codex CLI 0.157.1 was checked directly: with the catalog configured it made no `/v1/models` requests, and a changed file took effect only after an app-server restart. For that reason NEKODEX refreshes the file itself and asks for a Codex restart.

Before moving back to an older NEKODEX version, turn the model list off (`codex-chatgpt-web provider picker-off`). Older versions do not know this setting and would leave the list configured in Codex.
