# NEKODEX 5.4.0-nekodex.1

Prerelease for macOS and Linux, with a separate unsigned Windows preview with the September 19 upstream adaptations and Russian localization.

## Changes

- Russian language selection, NEKODEX-specific settings, usage, routing/update UI and native dialogs.
- Two/six-part context transport while retaining the threefold total context ceiling; conservative
  reasoning composer size and explicit owned HTTP 413 errors.
- Fresh-conversation connector metadata, current-turn steering authority, deferred tool discovery,
  literal plan markers and equivalent owned TOML hook keys.
- Persistent effort checks, live-turn observation backoff and safely bounded same-page rebind.
  Residual disconnected sessions are cleaned only after proven broker retirement; long tools and
  approval waits are not killed by an age-only timer.
- Localized catalog failure details and current system HTTP(S) proxy resolution for native requests.
- Lifetime usage breakdown, legacy-history migration, durable backup and explicit recovery notice.
- Isolated Windows payload-smoke source and certificate/native-history troubleshooting documentation.

## Evidence and scope

The existing runtime adaptations have nine focused tests plus an isolated Electron usage/storage
observation, successful TypeScript checks and development builds. Russian localization passed key/placeholder parity, TypeScript and renderer compilation, and an
isolated Electron check of language persistence and Russian usage/update/routing components. Full suites are not run. Distribution uses the
existing publisher signing, Apple notarization, artifact integrity and signed update metadata gates.

This release does not include upstream's debugger-injected tokenizer patch (#589) or Grok CLI
compaction (#590). External ChatGPT failures, quota availability, live long-context workloads and
arbitrary proxy configurations are not claimed solved. Unknown observed model identities remain
unknown. Existing accounts and route ownership are preserved by the normal update transaction.

Packages are provided for macOS ARM64/Intel and Linux x64. Windows x64 installer/ZIP builds are
published as explicitly unsigned Actions preview artifacts because Windows publisher credentials
are not configured. They are excluded from signed updater assets and retained for 90 days.
The default signed-Windows release path still requires Authenticode. No installed app is replaced.
