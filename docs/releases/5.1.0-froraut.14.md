macOS prerelease for Apple Silicon and Intel. This FroRaut fork preserves the upstream
application name and profile locations and replaces the existing Codex Web GPT installation.

### Changes

- Restore the ready state after successful ChatGPT capability inspection. Setup buttons no
  longer remain disabled with a stale connector-catalog refresh status after startup.
- Preserve verified staging acknowledgements when ChatGPT remounts conversation turns during
  a multipart context submission. Unknown or duplicate responses still stop the request.
- Report blocking submission dialogs immediately instead of waiting through the send deadline.
- Queue context-profile changes until the bridge is idle and show the active and pending modes
  separately. Confirm Web models in the actual Codex picker during setup.
- Accept canonical native app-tool names and their equivalent namespace/name form, while
  rejecting ambiguous exports.
- Distribute timestamped Developer ID application signatures, Apple notarization tickets,
  signed release metadata and GitHub build attestations. Publish only after the uploaded file
  digests match the signed assets.

### Validation and limitations

The previous installed build completed real native Codex Web High tool/read/final-answer work,
Web Instant image generation and desktop Web model selection. Six focused regressions cover
the context acknowledgement, dialog, tool-name, settings queue and setup fixes. One additional focused regression verifies readiness after capability inspection. This release
reuses that source evidence and performs the platform signing and notarization gates.

**The original large Web Pro task has not yet been demonstrated completing after compaction
with these fixes. Bigger Context remains experimental.** If the same failure recurs, cancel
the failed request, wait for the bridge to become idle, turn off Bigger Context in Settings
and start a new task with the normal context profile. Preserve the Activity error and version
when reporting a failure. A saved large-context setting does not prove its full capacity.

This release does not certify every model tier, native tool, account or operating system.
Intel packaging and notarization do not establish a live Intel ChatGPT session. Windows and
Linux binaries are not included in this macOS release.

The optional Hermes integration uses the selected Codex-runtime path. The separate direct
Hermes path still has an unresolved refusal after tool inventory and is not claimed fixed.
