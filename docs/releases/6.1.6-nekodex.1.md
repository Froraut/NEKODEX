# NEKODEX 6.1.6-nekodex.1

This prerelease lets you put away the network warning and fixes the browser and sign-in screens that did not look like NEKODEX.

## Changes

- **Dismiss or silence the network address warning.** The warning added in 6.1.5 now has **Dismiss**, which hides it on Overview and Browser until NEKODEX restarts or the verdict changes, and **Don't show again**, which is saved. A new Settings switch, **Warn about a changing network address**, turns it back on. NEKODEX keeps checking the route and logging the verdict either way.
- **New window is always visible.** Opening a separate browser window was only reachable inside the collapsed **Separate browser windows** section. A **New window** button now sits next to it in the browser tab row.
- **Sign-in screens match the app.** The Chrome profile picker used the old blue theme; it now uses the NEKODEX graphite and lavender palette. The passkey and existing-Chrome sign-in guides showed every action as plain text; the next step is now the main button, alternatives are secondary and Cancel is a text button.

## Downloads and trust

This version is a source prerelease. Published downloads remain `6.1.5-nekodex.1` until a release is dispatched from this tag.

## Verification and known limits

Root and launcher TypeScript checks, the renderer build and the architecture map passed. The screens were checked in the credential-free UI fixture (`launcher/scripts/ui-preview.cjs`, now with a `network-issue` parameter): Dismiss on both surfaces, Don't show again with the Settings switch, New window, and the passkey and Chrome sign-in cards. The profile picker page was checked with a stub profile list. The repository has no automated tests for these screens.
