# 6.1.26-nekodex.1

- Connections › Verify runtime: when NEKODEX is already checking the same ChatGPT account in the background, the runtime check now waits for it (up to 20 seconds) instead of reporting "Embedded launcher browser is unavailable". If the account is still busy, the message says so.
- A failed runtime check no longer shows "Local checks cannot prove that ChatGPT connector … is attached to this tunnel" next to an already verified connector; the connector is checked only after the runtime is healthy.
- Doctor results show the reason under each failed or warning check.

## Also in this release (from 6.1.25, which was not published)

- Task Center: a task waiting for a free browser slot keeps showing the account-readiness cause and the deadline that is still running behind it. Waits for capacity, runtime restart, account pacing and safety stops, a retained conversation that is no longer available, and restart or lease interruptions have their own labels.
- Tools proof: a completed task whose Codex tool returned without an error records the account, time and tool name. Overview and the account card show that fact instead of "a real tool task has not been tested yet". The proof is tied to the ChatGPT sign-in that produced it.
- OpenAI Platform sign-in: when Google refuses the embedded window, NEKODEX opens the same Tunnels or API keys page in the system browser and returns to the credentials step for the same account when you come back.

## macOS release

This prerelease provides macOS 13+ packages for Apple Silicon and Intel, with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. Windows and Linux packages are not part of this release; existing Linux downloads remain on 6.1.12.

The 6.1.25 release run stopped when Apple's notarization of the Intel DMG failed, so no 6.1.25 assets were published; 6.1.26 replaces it. The doctor and connector changes were checked on a notarized local Apple Silicon build. It does not claim an additional five-model, Intel, oldest-macOS or cross-platform interactive run for 6.1.26.
