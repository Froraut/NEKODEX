# NEKODEX 6.1.33-nekodex.24

This update improves recovery and everyday controls across the macOS interface.

- File lists finish loading when moving between pages, so Previous and Next remain usable.
- File → Close Window adds the standard Command-W shortcut on macOS. Closing a sign-in window cancels only its own sign-in flow; the main window keeps its existing close behavior.
- Native chat handoffs retain drafts after an uncertain result and provide a status refresh. Acknowledging the exact action in another window can release its local hold after a fresh status read, including after switching between chats. An unidentified outcome still prevents another send.
- Browser Companion 0.3.0 shows when sharing is stopping, prevents duplicate stop requests, and enables Stop only after the selected session has acquired its connection. Cleanup failures remain visible. The setup guide now explains that the dedicated selected-tab session must stay open; the popup can close.
- Chrome profile selection shows a loading state before profiles arrive.
- Tutorial videos show a localized error and Retry action when media cannot load.
- Remote folders distinguish an unloaded list, an empty folder, and an incomplete empty page.
- Identical Git-unavailable warnings are shown once, and PDF extractor metadata has clear spacing.

The update does not automatically resend uncertain browser or Native actions, create new account connections, or grant additional access.
