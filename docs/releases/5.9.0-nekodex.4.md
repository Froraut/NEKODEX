# NEKODEX 5.9.0-nekodex.4

- Dedicated passkey sign-in now targets the selected additional account, with a guarded handoff from embedded sign-in. Initial sign-in checks support cancellation instead of indefinitely holding browser ownership.
- Browser errors appear above the embedded page. Tabs display the cat icon, status indicator and full title, with horizontal scrolling for long tab lists.
- Open multiple NEKODEX browser windows using the selected account session. macOS supports native grouped tabs, Cmd-T/Cmd-N and Control-Tab switching. Automated task pages remain independent; closing respects unsaved-page vetoes.
- Includes the Native statistics outbox, background proxy refresh and session diagnostics from .3.

Focused backend, renderer and actual isolated Electron window/tab checks passed; details are in `docs/reviews/passkey-secondary-tabs-20260921.md`. Actual passkey authentication still requires the user's browser/biometric interaction. Prepared for local signed Apple Silicon installation; this file does not assert a public or cross-platform release.
