# NEKODEX 6.1.10-nekodex.1

This prerelease fixes the last two places where keyboard focus was lost.

## Changes

- **Hide ChatGPT during a passkey sign-in.** Focus now moves to the **Sign in to ChatGPT** heading. It used to drop to the top of the window, because the button that replaces the ChatGPT view is disabled while the passkey sign-in waits.
- **Try again on the startup error screen.** If NEKODEX still cannot start, focus returns to the new **Try again**. Otherwise it lands on the first page heading, or on the onboarding step heading when onboarding opens.

## Downloads and trust

This version is a source prerelease. Published downloads remain `6.1.9-nekodex.1` until a release is dispatched from this tag.

## Verification and known limits

Root and launcher TypeScript checks, `bun test`, the architecture map, the version check and the renderer build passed. The fixture's keyboard smoke test (passkey sign-in, startup error, Browser, Overview) finds no action that leaves focus on the page body in dark or light. A scripted retry run also covered a second failure, onboarding and a successful start.
