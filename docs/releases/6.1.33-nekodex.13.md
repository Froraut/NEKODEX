# NEKODEX 6.1.33-nekodex.13

- Attach a set of up to eight macOS windows to one Agent task. The agent can read each selected window; add and remove windows without restarting the desktop helper.
- Keep desktop clicks tied to a settled foreground frame when returning from the approval panel. Input still uses the original observation and never retries automatically.
- Keep one initial desktop-control confirmation for the helper session. Adding windows and switching among them does not request Allow again; restarting or explicitly releasing the helper still requires a new confirmation.

This is the standard macOS Apple Silicon update. Browser companion behavior is unchanged.
