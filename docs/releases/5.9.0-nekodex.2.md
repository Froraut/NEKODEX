# NEKODEX 5.9.0-nekodex.2

This release adds account recovery, a quota overview, actionable Activity diagnostics, and targeted Web connection repair, alongside the completed security and reliability fixes.

- Retry a temporarily unavailable authentication check without signing in again or losing the saved account identity. Only a verified session permits new requests.
- Refresh quotas across accounts with up to three concurrent checks. Keep last-known values during temporary failures and distinguish current, stale, unavailable and skipped results.
- Inspect failures and request durations by account and model in Activity, with outcome breakdowns and explicit sample coverage instead of misleading low-sample comparisons.
- Repair an eligible Web tunnel without restarting a healthy Native service. Overview and Connections share consistent readiness and next-action guidance.

- A blocked external navigation preserves the current ChatGPT conversation and renderer readiness. A committed foreign main-frame document still permanently clears the old binding; iframe redirects do not trigger the main-page replacement restriction.
- The macOS terminal runtime installer is available again. It requires trusted, preinstalled Node.js and authenticates signed release metadata, the runtime archive and all installed license files before extraction or execution. Failed replacement restores the previous runtime, CLI link and notices.
- Web subagents settings now explain JavaScript orchestration and the commands/individual tool calls that remain available when the setting is off. The raw-exec-off security restriction is retained.

Development evidence: focused installer authentication/rollback tests, retained-origin tests, actual isolated Electron navigation controls and foreign-commit rejection, and the source DEV settings screen. Native and Web provider/account functionality remains a separate live-service check.

The four-feature change completed four waves of 16 Sol review/implementation lanes. Focused backend and UI checks, launcher TypeScript, the renderer build, and four isolated browser flows passed; accepted independent-review findings were corrected and rechecked. Live provider/account behavior was not exercised by those fixtures. Details: `docs/reviews/major-benefits-20260921.md`.

Distribution targets are signed and notarized macOS DMG/ZIP for Apple Silicon and Intel, plus Linux x64 AppImage. Windows x64 is an explicitly unsigned preview in the matching GitHub Actions run, not an authenticated in-app update. Packaging verifies native signatures, notarization and artifact integrity separately from development behavior. Installation remains user-controlled.
