# NEKODEX 5.9.0-nekodex.2

This build completes the security fixes with narrower compatibility boundaries.

- A blocked external navigation preserves the current ChatGPT conversation and renderer readiness. A committed foreign main-frame document still permanently clears the old binding; iframe redirects do not trigger the main-page replacement restriction.
- The macOS terminal runtime installer is available again. It requires trusted, preinstalled Node.js and authenticates signed release metadata, the runtime archive and all installed license files before extraction or execution. Failed replacement restores the previous runtime, CLI link and notices.
- Web subagents settings now explain JavaScript orchestration and the commands/individual tool calls that remain available when the setting is off. The raw-exec-off security restriction is retained.

Development evidence: focused installer authentication/rollback tests, retained-origin tests, actual isolated Electron navigation controls and foreign-commit rejection, and the source DEV settings screen. Native and Web provider/account functionality remains a separate live-service check.

This record describes the source/local build. It does not by itself assert a public GitHub release or installation on another machine.
