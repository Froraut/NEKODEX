- Task Center: a task waiting for a free browser slot keeps showing the account-readiness cause and the deadline that is still running behind it. Waits for capacity, runtime restart, account pacing and safety stops, a retained conversation that is no longer available, and restart or lease interruptions now have their own labels.

- CI runs the tool-proof and Google-handoff checks with the focused regressions.

## macOS release

This prerelease provides macOS 13+ packages for Apple Silicon and Intel, with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. Windows and Linux packages are not part of this release; existing Linux downloads remain on 6.1.12.

The focused regression suite and version checks run on pull requests. The changed Task Center and external-browser handoff were checked in the development preview. A successful tool result is recorded only after a completed, connector-bound turn; sign-in identity changes hide or retire the saved proof.

The five-model conversation and file-read acceptance from 6.1.24 remains evidence for the unchanged model transport. It does not claim an additional five-model, Intel, oldest-macOS or cross-platform interactive run for 6.1.25.
