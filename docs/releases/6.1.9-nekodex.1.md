# NEKODEX 6.1.9-nekodex.1

This prerelease lists the Web models each account's ChatGPT model picker actually offers, and keeps that list current without a NEKODEX release.

## Changes

- **Web models are discovered, not hard-coded.** The account check now visits every row of ChatGPT's model picker and every unlocked level, and reads which model each level runs from the picker's own description. Codex lists one Instant, one thinking (Medium, High, Extra High) and one Pro row per model, named as ChatGPT names them, for example GPT-6 Pro, GPT-5.6 Sol Pro, GPT-5.6 Sol, GPT-5.6 Sol Instant and GPT-5.5. Existing model IDs keep working. Latest's lower levels run GPT-5.6 Sol, so they never appear as GPT-6 rows.
- **The list keeps itself current.** Every browser check (startup, Check account, Repair) saves the selected account's models, and NEKODEX re-reads the picker every six hours while the account is idle and its browser is out of view. The running service picks the change up immediately and rebuilds Codex's model list; fully quit and reopen Codex to see it. Switching accounts switches the list.
- **Codex is told when to restart.** Confirming the models in Codex records which Web rows were confirmed. Whenever the catalog Codex would load differs from that, whoever rewrote it, Overview, Setup and Settings ask you to fully quit and reopen Codex and confirm its picker again. A served catalog request no longer clears that request, and pickers confirmed before this release are reconfirmed once.
- **Turns select the right row.** A model is always chosen through the picker row that names it, or through Latest when it is the newest model. Older Instant/Medium/High/Extra High tasks stay on GPT-5.6 Sol, and unpinned Pro runs the newest discovered Pro model, so a turn on another model can no longer change what they run. Hermes and Claude clients can use every discovered model.

## Downloads and trust

This version is a source prerelease. Published downloads remain `6.1.8-nekodex.1` until a release is dispatched from this tag.

## Verification and known limits

Root and launcher TypeScript checks, `bun test` (including headless-Chrome fixtures of an English and a French picker), the architecture map and the version check passed on the discovery changes; later picker-restart changes were verified with focused tests and the renderer build in the UI preview (`?scenario=picker-refresh`). Live discovery against a signed-in ChatGPT account was not run before this release, because the local NEKODEX browser sessions were signed out.
