# NEKODEX 6.1.9-nekodex.1

This prerelease lists ChatGPT's five thinking levels in the Codex picker exactly as ChatGPT runs them, and keeps their availability current from each account's model picker.

## Changes

- **Five Web models, as ChatGPT runs them.** Codex lists GPT-5.6 Sol Instant, GPT-5.6 Sol Medium, GPT-5.6 Sol High, GPT-5.6 Sol Extra High and GPT-6 Astra Pro, each with one fixed level and its own context budget. GPT-5.6 Sol Pro and the generic GPT-5.6 Sol row are no longer listed; tasks saved with them, and older IDs, keep working.
- **Availability comes from the account's picker.** The account check visits every row of ChatGPT's model picker and every unlocked level, and reads which model each level runs from the picker's own description, so a level the plan locks is not listed and Latest's lower levels never count as GPT-6.
- **The list keeps itself current.** Every browser check (startup, Check account, Repair) saves the selected account's evidence, and NEKODEX re-reads the picker every six hours while the account is idle and its browser is out of view. The running service picks the change up immediately and rebuilds Codex's model list; fully quit and reopen Codex to see it. Switching accounts switches the list.
- **Codex is told when to restart.** Confirming the models in Codex records which Web rows were confirmed. Whenever the catalog Codex would load differs from that, whoever rewrote it, Overview, Setup and Settings ask you to fully quit and reopen Codex and confirm its picker again. A served catalog request no longer clears that request, and pickers confirmed before this release are reconfirmed once.
- **Turns select the right row.** A model is always chosen through the picker row that names it, or through Latest when it is the newest model. Older Instant/Medium/High/Extra High tasks stay on GPT-5.6 Sol, and unpinned Pro runs the newest discovered Pro model, so a turn on another model can no longer change what they run. Hermes and Claude clients list the same five models.

## Downloads and trust

This version is a source prerelease. Published downloads remain `6.1.8-nekodex.1` until a release is dispatched from this tag.

## Verification and known limits

Root and launcher TypeScript checks, `bun test` (including headless-Chrome fixtures of an English and a French picker), the architecture map and the version check passed on the discovery changes; later picker-restart changes were verified with focused tests and the renderer build in the UI preview (`?scenario=picker-refresh`). Live discovery against a signed-in ChatGPT account was not run before this release, because the local NEKODEX browser sessions were signed out.
