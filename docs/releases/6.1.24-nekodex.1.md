# NEKODEX 6.1.24-nekodex.1

This macOS prerelease fixes Web-model conversation continuation and local-tool results in Codex Desktop. It also includes the account and tunnel recovery improvements developed since 6.1.12. The existing Codex Native6 connector remains compatible.

## Web models and conversations

- Continue a conversation or return a local tool result without the `known input item must satisfy its schema` error. Codex Desktop's null optional reasoning fields are accepted; malformed populated fields still fail validation.
- Receive the completed Medium, High and Extra High answers when ChatGPT replaces its thinking renderer. NEKODEX follows only the accepted response and rejects an unrelated new user turn.
- Preserve the saved conversation when an unready account prevents a request from being sent.

## Accounts, tools and browser

- Unready Web accounts report their actual cause and account name in Codex. Temporary sign-in, startup and inspection states can finish; persistent missing requirements give an actionable error.
- Account-tunnel setup can settle its own background inspection before connecting. New or reconfigured tunnel aliases are isolated by application profile, account and mode, avoiding collisions with DEV. Existing bindings are preserved unless explicitly reconfigured.
- A temporary unavailable authentication check no longer invalidates a model or connector inspection as if the user had signed out. Confirmed sign-out and account changes still invalidate readiness.
- Browser navigation has an editable address bar and improved task, account and connection status controls.

## Downloads and verification

This release provides macOS 13+ packages for Apple Silicon and Intel. Both architectures require timestamped Developer ID signatures, Apple notarization and stapled tickets. Release assets also carry signed NEKODEX metadata, SHA-256 checksums and GitHub build attestations. No Windows or Linux package is included in this macOS-only release.

The installed Apple Silicon build was exercised in Codex Desktop with all five Web choices: GPT-5.6 Sol Instant, Medium, High, Extra High, and GPT-6 Astra Pro. Each continued its conversation, executed a real local file read with exit code 0, and returned the correct derived number and file contents. Focused parser, response-rebinding, type and version checks passed. These checks do not claim a new Intel interactive run, an oldest-supported-macOS run, or a full cross-platform feature audit.

For command-line installation of this macOS version, select `CODEX_CHATGPT_WEB_VERSION=6.1.24-nekodex.1` explicitly. The general installer default remains the previously advertised multiplatform release.
