# NEKODEX 5.6.0-nekodex.2 — Native6 startup recovery

Includes Native6 from 5.6.0-nekodex.1 and fixes the installed upgrade failure observed with a closed ChatGPT reasoning menu.

- Account capability detection now uses the same owned-menu click/pointer activation as task turns, including recovery from stale expanded state, instead of assuming Enter mounted the slider.
- Missing reasoning controls still fail explicitly rather than inventing account capabilities; the post-activation slider wait is bounded to 15 seconds.
- The Native6 action opens setup recovery when core setup is incomplete instead of silently doing nothing.

One focused regression passed for closed-menu capability activation. Prior Native6 checks remain valid. No full suite was run. Native4/5 remain supported until explicit migration; Native6 requires a newly created and verified ChatGPT connector.
