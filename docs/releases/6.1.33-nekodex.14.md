# NEKODEX 6.1.33-nekodex.14

- Native account and model checks use the system network route from the first request. On a slow VPN they no longer stop at `workspace routing discovery timed out` before the account answers.
- Native account and metadata requests wait up to 30 seconds instead of 15. Account and routing validation are unchanged, and no request is replayed.

This is the standard macOS Apple Silicon update.
