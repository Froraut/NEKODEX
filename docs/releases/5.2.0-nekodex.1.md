# NEKODEX 5.2.0-nekodex.1

The first NEKODEX-branded macOS prerelease: a desktop workspace for ChatGPT accounts,
Codex model connections and local tools, maintained by FroRaut.

## Install

Choose `NEKODEX-5.2.0-nekodex.1-mac-arm64.dmg` for Apple Silicon or
`NEKODEX-5.2.0-nekodex.1-mac-x64.dmg` for Intel. Requires macOS 13 or later.
Quit the old application, open the disk image, and drag NEKODEX into Applications.

The first transition from Codex Web GPT requires manual installation because the executable
was renamed. Existing profile locations and bundle identity remain compatible. Keep profile
data when removing obsolete app bundles. ZIP/runtime filenames retain compatibility prefixes.

## New desktop identity

- NEKODEX name and original cat icon; graphite/lavender design.
- Responsive Overview, Accounts, Browser, Setup, MCP, Activity and Settings surfaces.
- Consistent larger typography, corrected scrolling, state-aware setup and eight recent events.
- Animated cat expressions, paws and original-shape tail, with reduced-motion support.

## Backend reliability

- Fixed helper shutdown during startup and retained physical ownership during cleanup.
- Preserved task-account routing across IPC and deferred durable affinity until acquisition.
- Restored local Web history when continuing on a native model.
- Prevented failed checkpoint reads from authorizing silent overwrites.
- Included detached compaction in drain decisions and surfaced partial shutdown cleanup.
- Corrected Manual-mode tunnel-key import and isolated managed Chrome login attempts.
- Added recoverable uninstall journal states and compensation for failed final route setup.
- Explicitly rejected unsupported inline file data and retained opaque reasoning metadata locally.
- Bounded response event accumulation, admin bodies, activity tombstones and emergency logs.
- Replaced Windows eager tee observation with demand-driven stream delivery.

MCP invocation cancellation intentionally still retires the whole turn binding. Opaque reasoning
is not converted into readable prompt text. Configured parallel capacity is not measured sustained
capacity or additional subscription allowance.

## Packaging and evidence

The macOS release pipeline signs the application and final DMG with Developer ID, requires Apple
notarization and stapled tickets, validates the app/runtime and Gatekeeper, then signs metadata,
attests final assets and checks uploaded digests before publication. Both Apple Silicon and Intel
packages are built on matching GitHub runners. Windows and Linux binaries are not included.

Development readiness reuses eight focused backend regression cases, successful typechecking,
a source launcher build/DEV launch and the installed local backend startup from the preceding
fix task. The release-only changes receive version consistency and manual packaging review;
full behavior suites are not repeated.

Live Windows execution, every model/account combination, large sustained concurrency and all
fault-injection recovery paths remain unverified. Bigger Context remains experimental. See the
[backend fix report](https://github.com/Froraut/codex-chatgpt-web/blob/v5.2.0-nekodex.1/docs/reviews/2026-09-15-sol-backend-fixes.md).
