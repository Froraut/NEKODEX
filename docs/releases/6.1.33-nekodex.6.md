# 6.1.33-nekodex.6

## Agent mode

- The semantic reviewer returns its verdict in a fenced JSON block, and NEKODEX also accepts a verdict whose punctuation the ChatGPT Markdown conversion escaped, so verdicts are no longer lost as invalid output.
- Desktop evidence now carries the click's observation, coordinates and window point, the observed window size, and element bounds (no pixels), so a reviewer can judge whether a click hit its target.

## Native accounts

- Owner recovery no longer refuses because of an exited, unreaped (zombie) process of another app. Only a process the kernel reports as a zombie of the same user is excluded; every other uninspectable process still blocks recovery.

## Interface

- The sidebar no longer repeats "Workspace" under the "Local workspace" header.

## macOS release

This prerelease provides a macOS 13+ package for Apple Silicon only, built by the release workflow with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. Intel Macs stay on 6.1.33-nekodex.4.
