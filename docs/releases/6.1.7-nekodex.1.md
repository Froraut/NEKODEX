# NEKODEX 6.1.7-nekodex.1

This prerelease moves every launcher screen onto the NEKODEX design system and adds a light theme.

## Changes

- **One design system on every screen.** Overview, Accounts, Browser and sign-in, Activity, Task center, Connections, Updates, Settings and Onboarding now use shared components and tokens (buttons, panels, notices, setting rows, setup rows, meters, steps, dialogs, toasts) instead of about 1,400 lines of per-screen CSS. The sidebar, titlebar and page widths are the same everywhere.
- **Appearance: Dark, Light or System.** A new Settings row picks the launcher theme. Dark stays the default, so nothing changes until you choose otherwise. ChatGPT pages keep following your computer's setting. The Chrome profile picker follows the launcher theme.
- **Overview says what to do next.** One focal panel names the current state and the action that fixes it, the network notice sits right under it, and connection rows, the Connections page and its tabs now agree on status, colour and action.
- **Calmer account cards.** Each card shows the account, its facts and allowance meters up front; sign-in, models, tools setup, pacing and proxy moved into collapsible sections.
- **Settings has an On this page rail** that follows the section in view, and saving one setting no longer dims the whole page.
- **Keyboard and screen readers.** Controls keep focus while they are busy, dialogs return focus when they close, error toasts stack above dialogs and no longer cover page actions, Connections tabs are a real tab list, and new text is available in all six languages.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Root and launcher TypeScript checks, `bun test`, the architecture map, the version check and the renderer build passed. Every screen was captured in the credential-free UI fixture (`launcher/scripts/ui-preview.cjs`, which now mocks every launcher API method) in dark and light, in English and Russian and at 760 px, with no page errors, overflow or clipped text, and a script clicked every control and walked each screen with the keyboard. The traffic-light alignment and window dragging were not checked in a packaged window before tagging.
