# 6.1.33-nekodex.5

## Agent mode

- The independent semantic review reads only the reviewer's final answer, so commentary such as the "Local tools unavailable" notice no longer makes every review invalid. An invalid reply keeps a short, redacted copy for diagnosis and no longer uses up a review attempt; the same action is still never resent.
- Semantic review, Verify and browser-companion refusals now show their exact reason instead of a generic error.
- A send whose outcome is unknown can be closed explicitly on a stopped task: "Record outcome" records it as abandoned (or as delivered when its acceptance receipt exists). Nothing is resent, the history is kept, and the task can then be archived.
- When Native models are offline after a restart, Agent mode and Agent tools show a one-click "Check account and models".

## Desktop tools

- Pixel clicks are delivered to the exact selected window. Previously a click could be reported as dispatched while the application never received it. A window that moved since its observation is refused before input.

## Native Codex threads

- A handed-off thread keeps its own service tier, and approvals requested during the handoff turn are answered with Codex's own decline.

## Browser companion

- The Chrome extension has a fixed ID, `bocnhdmjkjcoedkephdeoeipmmfbanpc`, which no longer changes with each update.
- Only Local API requests that name the bound account with `X-NEKODEX-Companion-Account` go through a bound ChatGPT tab; all other turns use NEKODEX's own browser.
- The model version is filled in from the selected mode, the popup shows when NEKODEX revoked a pairing, and packaging requires every extension file.

## macOS release

This prerelease provides a macOS 13+ package for Apple Silicon only, built by the release workflow with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. Intel Macs stay on 6.1.33-nekodex.4. Windows and Linux packages are not part of this release.
