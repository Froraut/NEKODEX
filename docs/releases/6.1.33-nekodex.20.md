# NEKODEX 6.1.33-nekodex.20

- Desktop Helper now shows a readable, opaque consent window with local text and standard Don't Allow / Allow buttons. Its asynchronous answer lets the AppKit application keep drawing and handling input while consent is pending.
- Return, Escape and closing the window refuse desktop access. Only explicit Allow plus a current caller-owner check records consent. The existing process-local lifetime and unbounded human decision time are preserved.
- Helper identity, TCC permission scope, selected-window restrictions and approved-input checks remain unchanged. This does not bypass macOS permissions or grant desktop access automatically.

Development verification used the actual presenter in a separate inert preview: readable on-screen UI, Return/Escape/close refusal, and an explicit Allow choice that still created no provider or desktop authority. Installed-helper verification remains a separate step through the normal application update.

This includes the .19 startup-recovery fix and .18 UI improvements. Website and iOS work remain separate.
