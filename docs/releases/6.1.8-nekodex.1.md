# NEKODEX 6.1.8-nekodex.1

This prerelease fixes keyboard focus that was lost after a few actions in 6.1.7.

## Changes

- **Keyboard focus stays in place.** After these actions, focus used to drop to the top of the window, so keyboard and screen reader users had to find their place again. Focus now stays on the control or moves to the control that replaced it:
  - **Sign in to Codex** on an account card;
  - **Open now** in the Browser's list of separate windows;
  - **Upgrade to Native6** and **Use Native4** in Connections;
  - **Repair Web transport**;
  - **Sign in to ChatGPT**, which opens the Browser screen and now lands on its heading.

## Downloads and trust

This version is a source prerelease. Published downloads remain `6.1.7-nekodex.1` until a release is dispatched from this tag.

## Verification and known limits

Root and launcher TypeScript checks, `bun test`, the architecture map, the version check and the renderer build passed. A script activated every control on the affected screens in the credential-free UI fixture, in dark and light, and found no action that leaves focus on the page body. Two cases outside these screens still lose focus in the fixture: **Hide ChatGPT** during a passkey sign-in and **Try again** on the startup error screen.
