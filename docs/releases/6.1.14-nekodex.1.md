# NEKODEX 6.1.14-nekodex.1

This prerelease tidies the Connections page and the sidebar.

## Changes

- **The local tools steps are a progress indicator.** "Choose an accessible tunnel and API key",
  "Connect the local harness" and "Attach the ChatGPT connector" no longer act as buttons: clicking a
  finished or current step did nothing useful or jumped back in the setup. Back and Next move between
  steps; finished steps stay green with a check.
- **Sidebar selection marker.** The accent bar of the selected sidebar item now sits inside its
  highlight instead of on its rounded edge, where it looked like a broken border.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Root and launcher TypeScript checks, the architecture map and the version check passed. The renderer preview showed the three steps as plain list items (no buttons) on every step and the selected sidebar item's bar 4 px inside its highlight.
