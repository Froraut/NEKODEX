# NEKODEX 6.1.33-nekodex.28

- Desktop tools distinguish a rejected read on a live helper from a closed helper. A rejected read now shows Inspection required and offers explicit permission inspection without enabling desktop access again or replaying input.
- Refreshing window metadata leaves inspection required until current status is checked. Cached windows cannot be added to a task before that inspection succeeds.
- A closed helper still offers explicit Release then Enable recovery. Reading its status remains passive and cannot start or restart the helper.
- Healthy desktop access and the enabled state with no attached window retain their existing behavior.

This update retains the Native continuation tool-hint fixes from .27 and Browser Companion 0.3.0.
