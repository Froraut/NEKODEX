# 6.1.33-nekodex.10

## Updates

- A runtime switch no longer waits forever for an idle moment. It waits up to 60 seconds for one, then pauses new requests for up to 120 seconds while running turns finish, cancels any that remain, and switches. The Updates page shows the phase and a countdown and offers "Switch now".
- A paused runtime can no longer stay paused: every pause has a lease, a restarted launcher resumes an orphaned pause at once, and a watchdog resumes any unowned pause after 30 seconds. During a switch, new requests wait briefly instead of failing, and refusals say when to retry.
- A Finder `.DS_Store` inside an installed runtime no longer makes an update roll back.

## Browser companion

- Typing and clicking work while the NEKODEX window covers the browser during approval, as long as the selected tab is still active in its window.
- A ChatGPT send in a new chat is observed through the chat's first navigation to its own conversation address.

## Desktop tools

- Screen Recording is checked against "NEKODEX Desktop Helper" itself.

## Release pipeline

- Notarization stapling and ticket validation retry only when Apple's ticket service drops the connection.

## macOS release

This prerelease provides a macOS 13+ package for Apple Silicon only. Intel Macs stay on 6.1.33-nekodex.4.
