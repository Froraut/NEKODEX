# NEKODEX 6.1.33-nekodex.27

- Native Agent continuations refresh external tool descriptions from current host state, so a previous browser observation is no longer advertised as the current selected binding.
- Refreshing a hint preserves the original admitted tool IDs and input schemas. Missing, unsupported or schema-changed tools are omitted rather than granted new authority.
- Tool execution still requires its exact approval and matching receipt. An unknown outcome stays held; this change does not replay an action.

- Desktop tools distinguish an enabled preference from an unavailable helper, show the reported reason, and guide explicit Release then Enable recovery. Cached window rows are marked stale and cannot be added while the helper is unavailable.

This update retains the selected-account tools readiness fixes from .26 and Browser Companion 0.3.0.
