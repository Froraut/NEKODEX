# 6.1.29-nekodex.1

- Formulas are returned once, as their original LaTeX (`\(...\)` inline, `\[...\]` display), instead of the visual and accessibility copies together. A formula whose source is missing or ambiguous fails the turn rather than inventing one, and double brackets inside a formula are no longer turned into wiki links.
- Long answers with repeated paragraphs or headings (for example the same "Changed:" label in several sections) no longer fail with "changed a completed text block" when ChatGPT redraws or virtualizes earlier parts of the reply. Horizontal rules keep their place across redraws.
- Answer blocks are identified by their live page element, so a file preview appearing, changing its title or disappearing can no longer shift delivered text onto the wrong block. Text after a still-changing file preview is held until the reply completes.
- Blocks that receive their position data after being delivered keep it across later redraws; a delivered block moving to another position is still rejected.
- Alignment failures log structural evidence (block indices, tags, key mode), never answer text.

Adapted from upstream miuuyy/codex-chatgpt-web 6.1.4–6.1.8 (reply parsing, #769, horizontal-rule alignment).

Local app update; no public release assets.
