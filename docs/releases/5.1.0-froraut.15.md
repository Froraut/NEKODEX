macOS prerelease for Apple Silicon and Intel, preserving the existing Codex Web GPT profile.

### Retained-tab compaction repair

A completed browser helper can disconnect CDP and clear Chromium's effective device emulation
while the launcher still remembers the old viewport dimensions. Reusing that tab for compaction
could then time out before sending the handoff, producing the generic context-handoff error.

This release marks the exact owned tab's viewport for restoration when a completed tab is reused
or its helper owner changes. Existing on-screen/background presentation restores it before the
new helper uses the page. Conversation identity, connector binding and live-owner checks remain
in place. A focused regression exercises a collapsed renderer with unchanged cached dimensions
and confirms a working viewport is restored on reuse.

The pre14 real-world Instant compaction recovered through a fresh-tab fallback and Codex accepted
the replacement history. This release targets the initial retained-tab failure that caused the
visible reconnect. It does not claim every context/model path has been retested.

### Evidence and limits

- A small Instant native file-read/final-answer cycle completed in 20.51 seconds with a temporary
  minimal CLI configuration. Displayed output matched the file; raw Markdown escaped underscores.
- A resumed large Instant task completed a native read-only command and final review. A separate
  native compaction completed in 152.216 seconds on pre14 after the retained-tab failure and
  fresh-tab fallback. Codex installed six replacement-history items. The bridge estimated
  248,492 input tokens; this is not an API billing or maximum-capacity measurement.
- The earlier resumed Pro task executed tools but stopped with ChatGPT's Stopped thinking status
  before its final answer. That status did not identify a cause. Pro-specific completion remains
  unconfirmed, and Bigger Context remains experimental.
- The native cross-task send_message_to_thread delegation envelope is not yet recognized as a
  new instruction by the bridge's revision resolver. Ordinary user-message continuation works.

Both macOS packages must pass Developer ID signing, notarization, stapling, Gatekeeper and runtime
integrity gates before publication. Signed release metadata and GitHub attestations accompany
the assets. Windows and Linux packages are not included in this macOS release.
