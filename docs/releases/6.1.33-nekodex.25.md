# NEKODEX 6.1.33-nekodex.25

- Account allowance cards now distinguish current provider data from retained observations. Expired data or a failed refresh is shown as Last known, with the previously reported reset time and neutral meters.
- Opening Accounts refreshes an expired cached allowance once while preserving the previous values during the request. Missing percentages remain unreported; an explicit zero usage value still means 100% remaining.
- Empty or unrecognized quota responses no longer replace a known allowance with a misleading fresh result.
- Account cards name their separate ChatGPT connector explicitly, so its setup status is not confused with Native or Agent tools readiness.

This update includes the interface and Browser Companion improvements from .24. Companion 0.3.0 is unchanged.
