# NEKODEX 5.3.0-nekodex.1

macOS prerelease integrating the September 18 upstream compatibility review. This is a new feature release; existing account profiles, task affinity, connector identity and the in-app update transaction are retained.

## Reliability

- Read ChatGPT DIL/PUIK replies without requiring the legacy Markdown container.
- Give setup preflight the setup operation budget and hand a ready Launcher-owned MCP runtime to its supervisor without deliberately stopping it first.
- Bound forwarded native polling, handle a detached answer during proven MCP continuation, and preserve same-thread trusted environment state when incoming environment messages are historical.
- Stop rapid retry submissions after an observed rate limit with a persistent per-account cooldown. Surface the real structured compaction error and recognize the Korean rate-limit dialog.
- Detect indivisible oversized context records before sending. Preserve context rather than silently truncating it. Extra High availability alone no longer grants a Pro-sized context budget.
- Retry a rejected composer insertion once only when the editor has not changed, retaining exact prompt-integrity checks.

## Controls

- Experimental selected skills as named text attachments, with image/file and token budgets.
- Optional fresh chat for every turn, retaining local-tool attachment and thread/account ownership.
- A separate model for automatic Pro summaries: follow task, GPT-5.6 Extra High, GPT-5.6 Pro or GPT-5.5 Pro. A missing requested model fails before sending.
- Explicit Web-subagent setting; native-model delegation is unaffected. Existing profiles preserve prior behavior; new profiles default off.
- Per-account HTTP, HTTPS, SOCKS5 or HTTPS PAC proxy settings, and configurable pacing, breaks, concurrency and session duration.
- Local accepted-message statistics, including context-staging messages, with durable deduplication. These are observed counts, not official quota balances. Unknown models stay unknown.
- Manual submission timer from 30 to 600 seconds, default 120; selected passkey browser (Chrome or Firefox); runtime source/build identity in diagnostics.

## Evidence and prerelease limitations

Eight focused scenarios, backend/launcher type checks, and development builds passed. An isolated Electron run saved timer/browser preferences through IPC, rendered statistics without renderer errors, and read a DIL answer with a code block through the production observer. Full test suites were not run; this release reuses that focused evidence and the mandatory packaging/signature/notarization checks.

Signed-in Firefox passkey login is not live-verified: Firefox is absent on the development Mac. Capture uses only a newly created temporary profile; imported sessions still require the normal Launcher authentication check. It never reads an existing Firefox profile. If capture fails, retry with Chrome or use embedded login.

Live external proxy configurations, every paid Pro summary variant, provider throttling bursts, full long-context workloads, and Windows/Linux packages were not exercised. Proxy URLs with embedded credentials are rejected. If an optional context/model feature is unavailable, return it to the default in Settings after active tasks finish; account cooldowns cannot be bypassed through Resume. Existing account sessions and native route behavior must be assessed separately from the local fixtures. External ChatGPT safety rejections and provider outages are not claimed fixed.

macOS ARM64 and Intel packages retain the existing publisher identity. Windows and Linux are not part of this prerelease.
