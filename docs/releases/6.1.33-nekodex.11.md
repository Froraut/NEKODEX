# 6.1.33-nekodex.11

## Desktop tools

- The desktop helper runs from one stable place, `~/Library/Application Support/NEKODEX/Desktop Helper/NEKODEX Desktop Helper.app`, so a macOS permission granted once keeps working after updates.
- Development builds of the helper use their own bundle identifier, so a development build can no longer leave a stale Accessibility record that blocks the released helper.
- The helper asks for its own confirmation once per helper process instead of on every enable.

After installing, grant "NEKODEX Desktop Helper" Accessibility once at the stable path (remove any old entry first). Screen Recording grants keep working.

## macOS release

This prerelease provides a macOS 13+ package for Apple Silicon only. Intel Macs stay on 6.1.33-nekodex.4.
