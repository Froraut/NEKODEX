# NEKODEX 6.1.11-nekodex.1

This prerelease lists the Web models strongest first, makes Chrome sign-in retries and the launch screen clearer, and centres the macOS window controls.

## Changes

- **Web models strongest first.** Codex lists GPT-6 Astra Pro, GPT-5.6 Sol Extra High, High, Medium and Instant, in that order. Each keeps its fixed effort and context limit.
- **Chrome sign-in retries.** The last selected Chrome profile is kept for retries within the launcher session, without overwriting a verified account binding. The import shows the selected profile and gives clearer recovery guidance, and Cancel stays available while Retry or Continue is pending.
- **Launch screen.** A branded, localized loading screen replaces the minimal launch indicator, with reduced-motion support, a delayed retry and expandable failure details.
- **Window titlebar on macOS.** The traffic lights sit on the titlebar's centre line. In a narrow window, **Hide sidebar** in the open sidebar drawer can be clicked again; it used to start a window drag. The top of the sidebar and the onboarding bar now drag the window from edge to edge.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Root and launcher TypeScript checks, `bun test`, the architecture map and the version check passed. The model order, Chrome sign-in and launch screen changes passed their focused tests and a manual UI check, and a notarized build of the same source ran on macOS. For the titlebar, a drag-region audit in the credential-free UI fixture found no control inside a window drag region on any screen, in dark or light, and the screens are pixel-identical to 6.1.10. The traffic-light position and window dragging were not checked by hand in a packaged window.
