# NEKODEX 6.1.1-nekodex.1

This prerelease adapts upstream 6.1.1 and adds compatible features from the Enhanced fork, with the NEKODEX work merged since 6.1.0-nekodex.1.

## Changes

- Adapt upstream 6.1.1: separate activity and commentary from the final answer, the updated effort picker, file uploads, Manual prompt recovery, workspace grants, session checks and compaction. A completed broker response no longer waits for a socket close. A completed compaction no longer waits indefinitely for a summary it never submits.
- The model picker now lists named Web models: GPT-6 Pro, GPT-6 Astra and Astra Instant, GPT-5.6 Pro, GPT-5.6 Sol and Sol Instant, and GPT-5.6 Luna for Luna-only accounts. GPT-6 Astra appears only after the account's picker confirms it. The former fixed Light/Medium/High/Extra High/Pro IDs still work for saved tasks but are no longer offered.
- Detect the reasoning levels each model family allows, including French ChatGPT controls and model rows that load only when opened. A limited GPT-6 Pro no longer hides GPT-5.6 Pro. Hermes and the task history accept the named models.
- New opt-in clients under **Connections → Other clients**: Claude Code, a local Chat Completions / Messages API, and a Web-only mode for Codex. They use a separate revocable key that cannot reach Native or admin routes, and every client setting can be undone. All three stay off until enabled.
- Chrome sign-in: clearer failure and progress messages. On macOS, NEKODEX now asks for access to exactly the Chrome files it needs (profile list and connection file). The profile picker uses the available screen height and shows compact rows.
- If the interface process crashes, NEKODEX recreates the window around the existing browser session and draft. An explicit restart waits for idle work instead of refusing because the background network route is not ready.
- The `codex --profile nekodex` installer and the development smoke checks now use the named models.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Root and launcher TypeScript checks, the renderer build, version synchronization and the architecture map passed. Focused model, API, Claude, Web-provider and sign-in regressions passed.

The Codex catalog, cancellation, interrupt and V1/V2 subagent smokes passed with Codex CLI 0.157.1. A locally signed build of this source returned a real ChatGPT Web reply on macOS arm64, and its saved sign-in survived a restart. Codex CLI 0.157.1 and Claude Code 2.1.283 completed their protocol checks against inert model adapters.

The live Web subagent smoke and the Windows and Linux packages were not run before publication; the Linux and Windows packages are built by this release run. Provider challenges such as Cloudflare checks can still require the user after a restart. Decisions are recorded in [the 6.1.1 review](../reviews/2026-09-27-upstream-6.1.1.md) and [the Enhanced follow-up](../reviews/2026-09-27-enhanced-follow-up.md).
