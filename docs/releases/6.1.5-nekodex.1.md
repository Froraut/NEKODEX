# NEKODEX 6.1.5-nekodex.1

This prerelease tells you when your network, usually a VPN, is the reason ChatGPT keeps asking you to verify that you are human.

## Changes

- **Warning when the public address keeps changing.** Cloudflare ties its ChatGPT check to the public IP address that passed it. Some VPNs switch between several servers for each new connection, or send Cloudflare's check host (`challenges.cloudflare.com`) through a different server than ChatGPT. The check then fails or comes back after every restart, and NEKODEX cannot solve that for you.
- When Cloudflare blocks ChatGPT, NEKODEX now checks the addresses Cloudflare sees on several fresh connections. It runs at most once every ten minutes, using the account's own proxy settings.
- If the address changes, or the check host uses a different route, **Overview** and **Browser** show which of the two it is and what to change in the VPN. While the warning is shown, NEKODEX checks again every ten minutes and removes the warning once the route is stable.
- The addresses are compared in memory only. They are never saved, shown or written to logs. The log records only the verdict and the number of distinct addresses.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Tests cover a stable route, rotating ChatGPT addresses, a separate route for the check host, a failed trace, and a fresh connection for every sample. On a network that rotates VPN exits, the check reported `egress-unstable` with two ChatGPT addresses and a separate route for the check host. The existing tests, root and launcher TypeScript checks and the architecture map passed.

The check reads Cloudflare's public `/cdn-cgi/trace` diagnostic on `chatgpt.com` and `challenges.cloudflare.com` without cookies. A route that changes less often than the check samples may go undetected.
