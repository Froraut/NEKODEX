# NEKODEX 6.1.33-nekodex.17

- Keep an approved desktop action waiting while you return to its selected window. Refreshing task status no longer interrupts that wait, and repeated approval cannot repeat its input.
- Show when tools need a window, remote host or other task setup. Reserve “Unsupported schema” for schemas the validator rejects and display the actual readiness reason.
- Retain the Native account routing and multi-window improvements from previous releases.

Replaces the unpublished .15 and .16 release candidates.
