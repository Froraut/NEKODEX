# NEKODEX 6.1.13-nekodex.1

This prerelease makes the address bar of the ChatGPT browser editable.

## Changes

- **Editable address bar.** Click the address (or press ⌘L, Ctrl+L on Windows and Linux, even while the
  ChatGPT page has focus) to see the full URL with everything selected, ready to copy or replace.
  Enter opens the address; Escape restores the current one, and a second Escape leaves the field.
- **Short ChatGPT addresses.** `codex`, `/library`, `c/<id>`, `?temporary-chat=true`, `chatgpt.com/…`
  and old `chat.openai.com/…` links all open on chatgpt.com. ChatGPT pages load in the ChatGPT tab; task
  tabs keep the conversation their Codex turn resumes.
- **Other sites open in your default browser,** the same place a link clicked inside ChatGPT opens.
  Local and private addresses are refused, and invalid input is marked with a message in your language.
- While a Codex turn or a sign-in owns the browser, the address stays read-only, like Back and Forward.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

Root and launcher TypeScript checks, the architecture map and the version check passed. Focused tests cover address resolution (ChatGPT paths, hosts and aliases, external sites, refused schemes, credentials and free text), the ⌘L/Ctrl+L shortcut and typed external links through the link broker's public-host and DNS checks. The field's focus, selection, Enter, Escape and error behavior was checked in the renderer preview.
