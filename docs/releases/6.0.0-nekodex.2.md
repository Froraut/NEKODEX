# NEKODEX 6.0.0-nekodex.2

This local update collects the work merged into `main` after 6.0.0-nekodex.1 together with the post-review Native fixes from `codex/claude-review-20260925`.

- Usage statistics round consistently, label unknown values and keep incomplete CSV counts blank. Tiny nonzero completion rates show `<0.1%` or `>99.9%` instead of a false endpoint.
- Malformed Native requests receive typed client errors (400/413/415); unknown stream and internal errors propagate unchanged. Local writes are hardened.
- A live runtime keeps its ownership record when the launcher needs setup.
- Launcher contrast, tokens, error text, logout safety, locale formatting and accessibility are improved.
- Backend request handling, the telemetry outbox and control receipts are hardened; long native turns keep token usage and telemetry retries back off.
- Dead code is removed and duplicated helpers are shared across the ChatGPT Web adapter, Electron main/runtime/update code, the browser host, setup/CLI, browser automation, the service core and the launcher renderer.
- The automated test suites were removed from the repository.

Prepared for a signed local Apple Silicon installation. No public release, tag or other-platform build is asserted here.
