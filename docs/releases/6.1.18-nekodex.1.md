# NEKODEX 6.1.18-nekodex.1

This prerelease stops Web model tasks from waiting forever when their ChatGPT account cannot run them.
The Codex Native6 connector is unchanged: no new ChatGPT app is needed.

## Changes

- **Unready accounts fail with their cause.** Since 6.1.17 every ChatGPT account needs its own tool
  tunnel. A Web model task for an account without one, or for a signed-out account, stayed queued as
  "Waiting for capacity or account readiness", and Codex showed only a spinner. After 45 seconds
  NEKODEX now ends such a task before anything is sent to ChatGPT. Codex then shows which requirement
  is missing: a sign-in, the account's tool tunnel, a running tunnel, or a verified tools connector.
  Capacity, pacing and pause holds still wait as before.
- **The cause reaches Codex.** This failure is reported to Codex as a non-retryable `account_not_ready`
  error with that cause, not as "The ChatGPT browser tab was closed". Codex's automatic retry of the
  same turn receives the cause at once as HTTP 400, so it stops instead of reconnecting five times.
