# NEKODEX 5.2.0-nekodex.8

Keep Check for updates available even when an update has already been found. After the existing quota cooldown, a fresh check can replace an older offered package with the newest compatible published release without restarting the launcher. Checks remain blocked during download, verification and installation; installation is disabled while a check is starting.

Includes the packaged-updater identity fix from .7, the cat/full-version footer, signed GitHub feed fallback and complete in-app update screen.

## Development evidence

One focused controller regression passed: an existing 1.2.0 offer remains during cooldown, then a manual refresh selects the newly published 1.3.0 with exactly one additional fetch. The renderer bundle and version/link consistency check passed. The real source Electron renderer displayed both Download and restart and Check for updates for an available update. The available state was injected for this UI observation; no installation ran in the development profile. Temporary development processes and profile were removed. Existing successful updater/security checks were not rerun.

The release retains Developer ID signing, Apple notarization, signed release metadata and asset verification. The separately observed large-context compaction issue is not claimed fixed by this release.
