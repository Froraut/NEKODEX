# NEKODEX 6.1.33-nekodex.19

- If the launcher IPC bridge is unavailable, NEKODEX shows its startup recovery screen and diagnostic details. Surface adapters no longer throw during module import before that screen can appear.
- This follow-up retains the .18 UI improvements: grouped Agent tools with preserved drafts and exact calls, readable action summaries, reachable long-dialog actions, multiline fields, content-width layouts, and explicit loading or unavailable states.
- Native retains the bounded account-metadata retry introduced in .18. Sent threads and turns are never automatically replayed.

No account, permission, authentication, or model-execution behavior changes. This follow-up changes startup recovery and release metadata; the editable Figma .18 UI design remains applicable. Website and iOS work remain separate.
