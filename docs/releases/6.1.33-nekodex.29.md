# NEKODEX 6.1.33-nekodex.29

- Native desktop input guards bound each Core Graphics event-age query with monotonic clock samples. This fixes a reproduced estimator defect where a scheduling pause could appear to be new physical input.
- Action baselines use the measured lower bound; current-input and quiet-period checks use the upper bound. The original 5 ms physical-input threshold, all 13 event types, and key autorepeat detection are preserved.
- Each event query allows at most three samples with uncertainty no greater than 1 ms. Uncertain measurements fail closed with human-input-clock-uncertain; input is never replayed.
- Focused Swift development checks cover the controlled 29.93 ms scheduling pause, unchanged input, key-repeat timestamp changes, and ambiguous measurements.

This update retains the desktop inspection recovery from .28, Native continuation tool-hint fixes from .27, and Browser Companion 0.3.0.
