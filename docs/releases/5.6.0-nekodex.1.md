# NEKODEX 5.6.0-nekodex.1 — Native6

- Native6 is the default for new Automatic Full setups and has a visible upgrade action for existing installations. Existing Native4/5 connections keep their exact cached identity until explicitly migrated and verified.
- Native6 combines synchronous tools, owned asynchronous start/poll/cancel/ack, and metadata-only `codex_tool_status` for discovering owned operations after context or transport loss. Status does not reveal tool arguments/results or execute/acknowledge operations.
- Corrects async retry handling during compaction so an existing operation is not replaced by a fictitious completed invocation.
- A new ChatGPT connector with the exact Native6 name must be created and verified. Native4/5 schemas remain compatible; Manual Zero Risk4 is unchanged.

Operation ownership remains process-local. Cancelling after dispatch stops observation only. Expired payloads are reported as lost; automatic side-effect replay is not allowed. Native4 synchronous compatibility remains selectable.

macOS ARM64/Intel and Linux x64 use the protected release workflow. Windows is a separately labelled unsigned preview until Authenticode signing is configured.
