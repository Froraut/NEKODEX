macOS prerelease for Apple Silicon and Intel. Existing accounts and profile locations are preserved.

### Changes

- Native cross-task continuation: recognize the exact current-turn `send_message_to_thread`
  delivery only after checking its content and provenance against the local Codex journal.
  Unverified tool output and old-turn deliveries do not become new instructions. This supports
  the observed local root-task format; it is not a general permission to promote tool text.
- Compaction recovery: a retained-page viewport failure before Send can recover in the same
  operation through the existing fresh-page fallback. Cancellation and ambiguous/already-sent
  requests remain non-replayable. Progress reports distinguish preparation, fresh-page recovery,
  acknowledged transfer and summary receipt.
- Retained viewport coverage: a focused scenario exercises visible presentation, background
  transfer and the next owned turn after the prior helper disconnects.
- Resumable update downloads: authenticated partial files survive connection errors; retries
  request the remaining byte range. Incorrect range/size/hash is rejected. If a server ignores
  Range, the partial is replaced rather than appended. UI shows percentage, transfer speed and
  estimated remaining time. Downloads use an inactivity timeout plus an overall one-hour limit.
- Compatible updates: retain existing setup evidence only when the setup contract, account,
  route, capabilities and tunnel/connector identity match and no migration occurred. Show the
  last connector-verification timestamp instead of claiming a fresh verification. Older installs
  without the new contract receipt require one initial confirmation.
- Stopped-thinking diagnostics: show response presence, final-text length, active tool count,
  observed tool results and age of last tool progress. No prompt or tool contents are included;
  the status still does not identify its cause and never authorizes automatic replay.

### Evidence and limits

Nine focused cases passed for native delivery provenance, compaction pre-send versus post-send
failure, stopped-thinking evidence, visible/background reuse, compatible setup, resumed downloads,
corrupt bytes, interrupted transfers and ignored ranges. Core and renderer typechecks passed.
No full suites, large corpus replays, new image generation or Pro loop were run for these changes.

Earlier Instant read/final-answer and real large-history compaction evidence remains recorded in
the repository. The large compaction succeeded through pre14's recovery path; that does not prove
every current primary handoff or model tier. Bigger Context remains experimental. A user's actual
Stopped thinking result is not reclassified as a quota or policy failure without evidence.

Native signatures, notarization, metadata signatures and uploaded asset digests are enforced by
the release pipeline. This macOS release does not include Windows or Linux binaries.
