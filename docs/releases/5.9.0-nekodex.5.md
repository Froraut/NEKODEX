# NEKODEX 5.9.0-nekodex.5

Chrome passkey sign-in now offers existing profiles by name/email before creating an isolated profile, and remembers the choice per NEKODEX account. The selected normal Chrome profile opens without application modification or profile copying. Choose None matches for a new isolated login.

Import still requires Chrome connection approval. The ChatGPT account email is checked in an isolated temporary session before the selected NEKODEX partition is changed; a different or unverified account is rejected. Google sign-in alone is not treated as ChatGPT authentication.

Focused matching, account-isolation, fallback and cancellation checks passed. Prepared for signed local Apple Silicon installation; no public release or other-platform availability is asserted here.
