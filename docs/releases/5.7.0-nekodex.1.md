# NEKODEX 5.7.0-nekodex.1

This release improves runtime recovery and account controls while retaining Native6 as the default
for new Automatic Full setups. Saved Native4/5 and Manual connector identities remain compatible.

- Native requests no longer depend on the browser broker or tool tunnel being ready. Web requests
  report the unavailable capability explicitly, while the launcher recovers the tunnel separately.
- Runtime upgrades use a durable configuration generation and compare-and-swap rollback. A failed
  candidate can restore the previous validated runtime without overwriting a concurrent config edit.
- Application update readiness requires a locally usable lifecycle. An update from an older worker
  initially retains the previous working runtime and offers a guarded Restart NEKODEX action.
- Per-account Codex allowances show provider-reported windows, remaining percentages and reset times.
  Refresh is explicit; unsupported sessions and missing values are never represented as zero.
- Official Codex device sign-in uses the clicked account's browser session and an account-specific
  operation lease. It does not change Web task routing. The official authorization page still asks
  the user to confirm the account, and the running Codex desktop profile may require a restart.
- Native6 observation cancellation no longer leaves a completion fence stuck. Acknowledged operations
  release active capacity while retaining bounded replay protection. Oversized results fail with an
  acknowledgeable terminal outcome instead of becoming undeliverable.
- Continuation history is bound to the task identity and stored as shared history nodes within a
  bounded restart snapshot. Known local ownership failures stop before dispatch.
- Account identity checks ignore ordinary OAuth refresh. Lost browser/helper acknowledgements use
  exact-owner reconciliation, and retained-tab release no longer guesses the selected account.
- Connections groups model and tool setup. Statistics grouping/CSV, inline recovery, account forms,
  compact layouts, keyboard behavior, hit areas and reduced motion are improved in all six locales.
- Usage compaction preserves aggregates; Native telemetry retries retain the event ID and expose
  recorded-only coverage. Standalone installers now bind the expected publisher identity.

Development validation: seven focused cases, renderer and runtime type checks, 24 affected synthetic
Electron UI scenarios with a targeted layout correction, a synthetic login/copy/cancel interaction,
five further update/account design scenarios including a changing progress sample,
and a real isolated DEV startup with empty account state. See the review summary for precise limits.

macOS packages are Developer ID signed and notarized. Linux x64 is distributed as an authenticated
AppImage; the current-Arch symbol check is not a promise of compatibility with older distributions.
Windows is an unsigned preview Actions artifact until an Authenticode identity is provisioned.
