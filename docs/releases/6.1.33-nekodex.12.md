# 6.1.33-nekodex.12

## Desktop tools

- The macOS Window Sharing accessory no longer hides the actual selected application window from foreground checks. Exact application, window, focus and input-point checks remain in place.
- Explicit desktop enable waits for the helper confirmation instead of losing its launcher request after five seconds. The Allow dialog no longer expires after two minutes.
- An already confirmed helper stays available for a batch of operations, including after an ordinary rejected call. A new helper process still needs its own confirmation.

## Browser companion

- Companion 0.2.1 reports a visible ChatGPT response-rendering failure explicitly instead of returning its placeholder as an answer. It retains the uncertain-send hold and never resends automatically.
- Hidden error templates no longer interfere with ordinary replies, including replies that quote an error message.

## Verification and distribution

The changes passed focused native, IPC and browser-companion checks. Live acceptance verified a single companion API reply, the five-call browser task, a real desktop click with separate property verification, and an independent outcome review.

This update provides the normal signed and notarized macOS 13+ package for Apple Silicon. Intel Macs stay on 6.1.33-nekodex.4. Chrome Web Store and Firefox AMO publication are not included.
