# 6.1.27-nekodex.1

Fixes adapted from upstream 6.1.4–6.1.8 and the Enhanced fork (Evanlau1798, through v6.1.7-Enhanced.1).

- Large sends: Send waits until ChatGPT has processed every attached file (a failed upload is reported and the prompt is kept); backticks in the task history no longer freeze ChatGPT's tab; a large single message gets 180 s to be accepted, and acceptance is observed while the Send key press is still pending.
- Oversized messages: ChatGPT's "input too large" (inside a normal response stream or as HTTP 413) ends the turn at once with a "compact the task" error; a Cloudflare check on send is reported as such.
- Long turns: a turn whose own response stream is still open is not declared stalled when ChatGPT hides Stop; Stop and Think are recognized by their icons in every UI language, and a hidden Stop copy no longer counts as running.
- Replies: completion controls ChatGPT draws before the final text are accepted once generation stops, and a user message's footer is never taken as completion; compaction summaries are delivered in one piece.
- Model picker: NEKODEX waits for the effort menu to finish closing before checking it.
- Compaction: progress from a long-running task keeps renewing the compaction deadline while it settles, and the checkpoint request starts a fresh deadline (fewer `compaction_handoff_timeout` failures).
- Environment: a follow-up envelope that omits Codex's extra output folders or does not state network access no longer conflicts with the task's rollout, and root tasks keep their working directory after compaction.
- Tools: one-time approval cards are clicked (they ignore Enter) and must be unique; nested tool discovery tolerates exec status text; the Codex interrupt hook accepts the defaults Codex's settings write explicitly.
- Reliability: a browser operation abandoned by a cancelled task can no longer crash the shared helper; a late heartbeat cannot follow a task's end; helper stdout stays a clean protocol.
- Dependencies: fast-uri 3.1.8, ip-address 10.7.2, proxy-addr 2.0.8.

Local app update; no public release assets.
