# 6.1.33-nekodex.3

The first NEKODEX release built entirely by the release workflow since Apple Silicon got the Native worker and the execution VM. It is available for Apple Silicon and Intel. (6.1.33-nekodex.2 was a local build only.) For Intel Macs it is the first update since 6.1.28-nekodex.1, so the changes listed in the [6.1.33-nekodex.1 notes](https://github.com/Froraut/NEKODEX/releases/tag/v6.1.33-nekodex.1) apply too. The Linux VM and the Native worker remain Apple Silicon only.

## Replies and turns

- Instant replies show their first text about 1.5 s sooner on a new thread. NEKODEX picks up an admitted turn faster and releases the final paragraph as soon as it has stayed unchanged, without an extra fixed wait. Completion checks are unchanged.
- A ChatGPT error that replaces the assistant message now ends the turn at once instead of waiting for the timeout. ChatGPT's visible "message too long" alert is reported as a context-length error.
- Bigger Context stages that ChatGPT unmounts and remounts are no longer mistaken for the next Send.
- Auto-linked URLs in a message are matched only when the label equals the destination, and reading a collapsed message restores its collapse, focus and scroll position.

## Uploads, tools and compaction

- An upload ChatGPT rejects stops before processing, and a quota refusal (HTTP 429) is reported as such instead of being retried. Uploads use the active composer when ChatGPT keeps a hidden second one.
- Automatic tool approval waits until the requesting message has finished streaming.
- Codex 0.163 workspaces: extra writable roots granted by Codex are accepted, and a full-access task that omits its workspace roots after a Codex restart no longer conflicts.
- Compaction counts Codex's AGENTS.md refreshes as context rather than as a task, and the handoff deadline no longer runs down while the Mac sleeps.
- The runtime's API key is no longer passed to tunnel child processes.

Adapted from upstream miuuyy/codex-chatgpt-web 6.1.10–6.1.12 and the Enhanced fork (Evanlau1798, 6.1.10).

## Cleaning up

- Dead Native account profiles, revoked OAuth MCP providers and finished Agent tasks can now be removed from the app. A profile that is signed in or running asks for an extra confirmation. Removing a profile does not sign it out on OpenAI's side. Agent tasks are archived, not deleted: their records and evidence are kept.

## Installers

- `install-launcher.sh` without an explicit version now picks the newest release built by the release workflow and skips locally built ones such as 6.1.33-nekodex.1.

## macOS release

This prerelease provides macOS 13+ packages for Apple Silicon and Intel, with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. The Apple Silicon package uses the reviewed Native worker and VM guest that the workflow fetches by their pinned SHA-256 digests from the `native-inputs-b1ba58f7-32346218` release. Windows and Linux packages are not part of this release; existing Linux downloads remain on 6.1.12.
