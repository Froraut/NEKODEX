# 6.1.33-nekodex.7

## Desktop tools

- The macOS desktop helper now has its own stable identity for Screen Recording, Accessibility and event-posting permissions, so a grant survives NEKODEX updates instead of being lost with every version. After installing this release, grant the helper once in System Settings; Agent tools has a button that opens the exact panes.

## Browser companion

- The session page releases its sharing marker before reporting that sharing stopped, so a revoked pairing is shown reliably.

## macOS release

This prerelease provides a macOS 13+ package for Apple Silicon only, built by the release workflow with timestamped Developer ID signatures, Apple notarization, stapled tickets, signed release metadata and GitHub build attestations. Intel Macs stay on 6.1.33-nekodex.4.
