# NEKODEX 6.1.4-nekodex.1

This prerelease repairs sign-in import from Chrome and passkeys, and stops a signed-in account from showing "Verification unavailable" after NEKODEX restarts.

## Changes

- **Sign-in import works when Cloudflare checks the browser.** Before installing an imported session, NEKODEX checked the account with a request from outside any page. That request carries no Cloudflare verification, so ChatGPT now always answers it with a security check. The import then failed with "Chrome connected, but ChatGPT did not accept the imported session". When Cloudflare blocks that request, NEKODEX now installs the session behind the usual rollback and opens the ChatGPT page. After you pass the check there, it reads the account from that page and asks you to confirm it as before. If you cancel, or the sign-in does not finish within three minutes, the previous session is restored.
- **Signed-in accounts verify in the background again.** NEKODEX keeps each account's ChatGPT page in a hidden view, which draws no frames. ChatGPT therefore never measured the width of the message box there, and the account check treated a zero-width box as a page that had not loaded. After a restart the account showed "Verification unavailable: The ChatGPT page is not ready" until you opened Browser and retried. The check now accepts a laid-out message box in a hidden page.
- Includes the changes in [6.1.3-nekodex.1](6.1.3-nekodex.1.md): Web model names that match ChatGPT, one stable user agent for every page and frame, and the session check inside the ChatGPT page.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 remains an explicitly **unsigned preview** in the corresponding GitHub Actions run, outside trusted in-app updates. No Linux ARM64 release is claimed.

## Verification and known limits

A clean Electron session showed that ChatGPT answers every out-of-page session request without Cloudflare verification with a security check (HTTP 403, `cf-mitigated: challenge`). Tests cover recognising that check, and they show that a deferred import commits only the identity the page reported and the user confirmed. A headless browser test covers the message box check in a visible and a hidden page. The check was also run on a signed-in account's hidden page in the installed 6.1.3 build. It found the message box there, while the 6.1.3 check did not. The existing tests, root and launcher TypeScript checks and the architecture map passed.

An account whose ChatGPT session ChatGPT itself has ended still shows "The ChatGPT session has expired" and needs a new sign-in.
