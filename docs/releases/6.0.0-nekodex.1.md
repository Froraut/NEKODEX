# NEKODEX 6.0.0-nekodex.1

This prerelease brings the reviewed upstream v6 improvements together with the accumulated NEKODEX account, task, browser and architecture work since the last public release.

## Changes

- Add explicit Web model families and native Effort selection while preserving existing fixed-mode tasks and the native-first picker order. Detect locked upgrade positions before advertising or sending them.
- Add optional saved ChatGPT conversations in Automatic and Manual mode, independent of fresh-chat-per-turn behavior. Temporary Chat remains the default. Saved chats can apply ChatGPT memory and custom instructions.
- Support native memento compaction, verified checkpoint continuation and bounded recovery of original instructions. Preserve mixed environment/task messages and refuse recovery past an unproven newer instruction.
- Preserve a replacement Unix broker when the old listener closes; improve cancellation and browser acquisition ownership.
- Preserve streamed link destinations and literal file labels; coalesce ordinary authentication probes and recognize observed French/Korean Latest labels.
- Keep Interrupt-hook ownership intact after native TOML reserialization. Preserve custom providers, verified release metadata and existing account data.
- Recover rotated Activity logs, keep window title bars reachable after monitor changes and protect diagnostic source logs from filesystem-link exports.
- Include the existing task center, queue controls, account-specific tools onboarding, Chrome-profile login, browser workspaces, file handling and modular/lazy-loaded launcher improvements.

## Downloads and trust

macOS Apple Silicon and Intel packages require Developer ID signatures, Apple notarization and stapling. Linux x64 packages use authenticated NEKODEX release metadata and GitHub build provenance.

Windows x64 is an explicitly **unsigned preview** in the corresponding GitHub Actions run, with its own integrity hashes and preview notice. It is outside trusted in-app updates; Authenticode signing is not configured. No Linux ARM64 release is claimed.

This publication does not install or restart the application on the maintainer's computer. Finish active work before choosing the application's update/restart action.

## Verification and known limits

Reviewed source checks, core/renderer typechecks, development builds, isolated source Electron IPC/navigation and the affected Settings interaction scenarios passed. Focused fixtures cover model routing, compaction, Unix broker replacement, hook ownership, diagnostic export and platform helper behavior.

The additional live DEV account check on 2026-09-24 encountered ChatGPT session HTTP 403 / Cloudflare responses before account readiness. A successful live ChatGPT reply and the full authenticated saved-chat toggle were not established in that run. Reports #661–#663 and the remote-generation lifetime uncertainty in #339 remain separately tracked; this release does not claim those external incidents are fixed.

The exact upstream issue/PR decisions are in [the v6 review](../reviews/2026-09-24-upstream-v6.md).
