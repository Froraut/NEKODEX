# NEKODEX 5.2.0-nekodex.4

macOS prerelease for Apple Silicon and Intel, incorporating selected upstream v5.0.7 reliability fixes while retaining NEKODEX account routing and connector safeguards.

- Use local tunnel inventory and health discovery for readiness, avoiding optional remote status lookups.
- Observe responses revealed by CSS without a DOM mutation; recognize localized stopped-thinking statuses, including Russian.
- Cancel expired automatic tasks before disposing of their browser tabs, preserving exact owner identity.
- Restore the original profile environment when restarting after a startup failure.
- Improve content-free MCP diagnostic correlation and decoded history scrubbing while preserving native tool-call linkage.
- Show bounded localized Pro-unavailable explanations from the associated UI tooltip.
- Add Traditional Chinese and Korean launcher catalogs, account/settings flows, route diagnostics and native dialogs.
- Validate versioned download links against NEKODEX release artifact names.

## Compatibility

Existing profile locations and Codex Native4 / Codex Zero Risk4 connector identities are retained. No account credentials, capacity settings, account quotas or model context-limit policy are changed by this release. Existing legacy installations may require manual DMG installation as documented in the README.

## Development evidence

The implementation passed nine focused regression checks, backend and renderer TypeScript checks, version/download-link checks, and a renderer bundle build. The production response observer was exercised in isolated headless Chrome with a stylesheet change outside the response subtree. Other focused cases cover cancellation ownership, restart environment restoration, MCP correlation, native history linkage and language persistence. See `docs/reviews/2026-09-16-upstream-v5.0.7-implementation.md` for scope and limitations.

No full suite or live-account/proxy matrix was run. This release does not claim increased account quota, guaranteed context capacity, a measured global speedup, or resolution of upstream safety rejections. Native publisher signing, Apple notarization, signed release metadata and GitHub artifact attestations are enforced by the release workflow.

The .4 source was also opened in an isolated Electron DEV profile at 127.0.0.1:4186. Traditional Chinese settings text rendered and selecting Korean persisted through native IPC. Initial automation attempts selected the embedded ChatGPT window instead of the launcher, then assumed onboarding rather than the DEV settings flow; the check was corrected to target the exact renderer URL and settings controls. No runtime source correction was required. The temporary Electron/Vite session was closed; production accounts and routing were untouched. This does not constitute a complete visual or native-speaker language review.
