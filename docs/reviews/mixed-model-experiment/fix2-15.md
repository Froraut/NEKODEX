## Correction

### `L15-tunnel-install-CAS`

`installFileSnapshot()` now uses `lstatSync()` and fails closed for symbolic links and non-regular entries. The previous snapshot path followed links, so an owned atomic replacement could remove an originally linked inode and a later rollback could only restore its bytes at the path, not the link or the link target's ownership state. The new guard prevents installation or rollback from treating that layout as a managed regular-file installation. Missing paths still produce an empty snapshot, so absent-file compensation remains distinguishable from an external creation or edit.

The exclusive manifest lock remains a small owner-token lock for cooperating installers. It does not guarantee coordination with arbitrary external editors that ignore the lock, and the executable and manifest remain separate atomic replacements.
