## Result

No new root is counted as fixed in this wave. Fix1 had already classified `L03-write-ownership` and `L03-delete-ownership` as fixed; this Sol replacement lane corrected residual integration gaps in those same roots.

### `L03-write-ownership` residual correction

`writeFilesWithCompensation` now carries the complete initial `FileSnapshot` for every `managed: true` write. This preserves the absent-file case: a target that was absent at the operation snapshot cannot be overwritten after an external process creates it. Existing expected-byte journal writes continue to require the original bytes and file or symlink identity.

Compensation now records the exact post-write snapshot. When an owned atomic write replaces a symlink target inode, rollback accepts only that recorded post-write link, target, identity, and bytes, then restores the original snapshot through the same symlink. A different target inode, link, or content is treated as an external edit and preserved. Rollback of an initially absent target applies the same post-write ownership check before removing it.

### `L03-delete-ownership` residual correction

Managed removals now perform an immediate snapshot ownership check before `rmSync` and record only successful removals for compensation. Rollback no longer walks untouched paths, so a file created after an absent snapshot is not removed as collateral cleanup. The uninstall catalog and models-cache guards remain in place and unchanged in intent.
