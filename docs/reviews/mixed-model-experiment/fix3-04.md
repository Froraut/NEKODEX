## New corrections

- `L04-tunnel-key-probe` — In full mode, `runDoctor()` called `secureFile()` for the tunnel runtime key outside an individual probe boundary. A key that disappears or becomes non-stat-able after the existence check could abort the aggregate report before tunnel-service, tunnel-runtime, and connector checks. The tunnel-key probe now records a structured error and continues the remaining checks. Introduced by baseline.
- `L04-root-config-missing-profile` — Route diagnostics treated a missing root `config.toml` as loaded/invalid when a profile was requested, because the missing-config early return required no profile selection. Root absence now remains `configStatus: "missing"` with `config-missing`, regardless of the optional profile argument. Introduced by baseline.
