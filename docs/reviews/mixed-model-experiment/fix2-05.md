## Corrections

### L05-runtime-instance-proof

`currentRuntimeIdentity()` now accepts the supervisor's valid `ownerPid` even when both managed child PIDs are absent. Manual mode can therefore publish proof with a concrete launcher-instance identity (`ownerPid:0:0`) instead of publishing `null`, which would conflict with the persisted proof schema and make the positive proof transient or unreachable after reload. Managed daemon and tunnel PIDs remain part of the identity, so replacing either child changes the proof identity.

### Update cancellation error preservation

The `launcher:update-install` caller still awaits the Promise-returning `cancelInstall`. If cancellation cleanup rejects after `requestQuit()` returned a failure, the caller now throws an Error whose message is the original quit failure and whose `cause` retains the cleanup failure. The original requestQuit failure remains primary while cleanup diagnostics remain available.
