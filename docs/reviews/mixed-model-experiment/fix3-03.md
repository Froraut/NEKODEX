## Result

Corrected two residual integration gaps in the existing wave-1 and wave-2 ownership changes. No new root is counted as fixed; `L03-write-ownership` and `L03-delete-ownership` remain the accepted roots from the adjudication.

### `L03-write-ownership`

Compensation now snapshots removal paths with symlink target identity. If a later operation fails after removing an owned symlink, rollback restores the symbolic link and first verifies that its original target inode is still present. This preserves the resource type and avoids recreating a link to an externally replaced target.

### `L03-delete-ownership`

Uninstall now captures symlink-aware snapshots for the legacy catalog and models cache, and uses the same symlink-aware form during rollback. A same-content retarget or target inode replacement therefore fails the ownership check before deletion or restoration.
