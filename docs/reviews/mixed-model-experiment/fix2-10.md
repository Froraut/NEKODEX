## Result

Corrected one residual under `L10-broker-startup-rollback`. Fix1 had made failed startup cleanup inode-aware, but the ordinary `TurnBroker.close()` path still removed any socket-shaped path after clearing its server state. A close racing a failed startup, or a stale broker instance closing after another instance had taken the same path, could therefore remove another broker's live socket.

`TurnBroker` now retains the `dev/ino` identity of the socket created by its successful startup and removes a Unix socket during close only when the current path still matches that identity. Registry removal is also conditional on the registry still mapping the path to this broker. Startup cleanup uses a per-attempt token so a late failed-start handler cannot clear a newer attempt's state or registry mapping. The existing failed-start path still preserves the primary listen error and only removes a socket created by that attempt with a matching identity.

No changes were made to `src/dev-chat/driver.ts`, `src/dev-chat/cli.ts`, or `src/dev-chat/transport.ts`: fix1's malformed-call rejection, custom/freeform string ABI, optional `AbortSignal`, automatic-compaction propagation, manual cancellation path, and one-shot caller compatibility remain as source-reviewed. No unrelated compensation, proof publication, or external-edit code was refactored.

## Direct-caller and compatibility review
