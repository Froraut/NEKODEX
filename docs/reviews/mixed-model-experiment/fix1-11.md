## Fixed root

`L11-response-observation-failure` is fixed at the response DOM evaluation boundary.

When `responseTurn.evaluate` fails while the page remains open, `responseDomSnapshot` now throws a `TypeError` wrapper with the original failure as `cause`. It no longer returns an ordinary absent snapshot. The existing main turn loop can therefore apply its bounded internal observation-fault budget, instead of marking the iteration observed, resetting that budget, and entering missing-response handling. A no-result observation is treated the same way. Closed-page failures retain the existing `chatGptBrowserTabClosedError()` classification.

Cache fallback remains limited to an evaluate call that returned a known observer revision without a fresh snapshot. No public connector schema, connector name, or external authorization behavior was changed.

## Rejected root

The adjudication supplied no current source evidence for a valid assistant response whose usable Markdown root is hidden only through an ancestor, and changing that DOM contract would risk discarding content in hidden or virtualized browser views.

## Residual limitations

- Multipart acknowledgement and submission-boundary callers now receive the preserved observation failure rather than an absent response; their existing caller-level error handling remains the integration boundary.
