## Fixed roots

### `L12-retry-handoff-cancel`

Retry handoff creation was removed from `responseRequest().deliverEvent()`, where queue insertion happened before client-visible terminal translation. The HTTP bridge now calls a new internal `onProcessedTerminalEvent` callback after it translates a retryable adapter error into `response.failed`. The callback retains the existing exact 503, retryable, source-history, native turn identity, and source-hash guards, so public response schemas and authorization behavior remain unchanged.

Request abort and client stream cancellation both revoke the pending retry handoff through the existing retry-continuation owner. The bridge invokes client cancellation separately from its normal terminal cleanup, so normal terminal delivery can authorize the retry handoff before cleanup aborts the upstream turn, while cancellation before terminal processing cannot leave a successor claim behind.

The non-streaming response path applies the same guarded helper after queue collection, preserving its prior retry-handoff behavior while avoiding the streaming pre-delivery race.

### `L12-stream-queue-budget`

`AsyncEventQueue` now supports an optional byte measure and a maximum for bytes currently retained in its buffered array. The streaming HTTP queue enables the existing 32 MiB budget alongside the 10,000-event count limit. Bytes are added only when an event is actually buffered and released when that event is removed; events delivered directly to an awaiting consumer are not counted, and the total is not cumulative over the stream.

The delivery boundary now returns immediately after request cancellation. Cancellation also discards queued events and closes the queue through the request-owned cancellation path, preventing a late non-cooperating adapter callback or already-buffered stale event from reaching bridge terminal processing. Existing non-streaming cumulative accounting is preserved.

## Residual limitations

- No runtime, type, or focused test evidence was collected because the parent explicitly reserves shared fast verification and prohibited tests/typechecks/runtime actions for this lane.
- The byte measure is the UTF-8 JSON representation of each retained `AdapterEvent`; it bounds the queue's measured payload representation, while runtime object overhead and allocations inside a non-cooperating producer remain outside that accounting.
- Cancellation and terminal processing still depend on JavaScript scheduling order. The new callback and abort checks establish the ownership boundary for this HTTP path, but they cannot control a callback already executing synchronously on another execution context.
