## Correction

### `L15-tunnel-install-CAS`

The fix1 owner-token lock release ran in `finally` as a throwing cleanup operation. A release read/unlink failure could therefore mask the original write or rollback error, and could turn an otherwise successful installation into a failure. The release path now returns a bounded cleanup error instead: primary install/rollback failures remain primary with the lock failure appended, while a successful installation remains successful and emits a warning. The lock is removed only when its contents still match this install's token; a changed or unknown lock is preserved.
