## Result

Fixed both accepted roots.

### `L03-write-ownership`

`writeFilesWithCompensation` now turns `managed: true` writes into guarded writes using the bytes captured at the start of the operation. `writeIntegrationState` marks the managed config and hooks writes accordingly, so install, protocol replacement, disconnect, and reconnect paths refuse an intervening edit before writing. The guard also compares the captured regular-file `dev/ino` identity and the existing symlink link, resolved target, target identity, and bytes. Uninstall config and restored-hooks writes use the same current-snapshot check before committing their restored content.

The public connector schemas, connector names (`Native4`, `Native4 DEV`, `ZeroRisk4`), and external authorization behavior were left unchanged.

### `L03-delete-ownership`

Uninstall now checks the live catalog and models-cache snapshots immediately before deletion. A missing, replaced, edited, or identity-changed file causes the operation to preserve the external file and report an ownership conflict. The existing journal-copy guard remains unchanged.
