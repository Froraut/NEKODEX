## Implemented behavior

It waits for the predecessor before resolving the proxy environment, so overlapping provider calls retain invocation order. A cancelled waiter still holds its reserved slot until its predecessor settles; provider failure or cancellation after predecessor ownership releases that slot safely.

Every spawned tunnel control child now receives a supervisor-owned `AbortController`, removed with the child’s `close` settlement. Forced shutdown aborts all tracked control children, waits using the existing bounded recovery settlement interval, records an unsettled child as partial cleanup, and only queues a replacement tunnel stop after the previous control children have settled. A final bounded settlement check also covers the replacement stop command itself.

`stopChild` no longer sends an unconditional `SIGKILL` after `waitForChildExit` has observed `exit` or `close`. The pre-settlement graceful signal and bounded forced signal remain, as does the tunnel-control exit-path SIGKILL that can still be needed while the child’s streams/process group have not reached close settlement. This preserves required descendant cleanup while removing the stale post-settlement group signal.
