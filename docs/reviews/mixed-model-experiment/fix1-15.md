## Fixes

### `L15-updater-cancel-join`

`cancelInstall` in `launcher/electron/update.cjs` is now async. It sends the worker termination signal, waits for `close` or `exit` for a bounded five seconds, and deletes `tempRoot` only after child exit state is observable. If settlement cannot be proven, it preserves the owned temporary root and records `launcher.update_cancel_unsettled` for recovery. A kill failure other than `ESRCH` is recorded. The `main.cjs` caller must await the returned promise; lane 5 owns that caller integration as requested.

### `L15-tunnel-install-CAS`

`src/tunnel.ts` now creates a small exclusive `${manifest}.lock` with a random owner token around the final installation snapshot, executable replacement, manifest replacement, and rollback path. A cooperating installer seeing the lock fails closed. Release only unlinks the lock when its contents still match the owner token; an existing or unknown lock is never deleted. The final snapshot is repeated after lock acquisition, so a change during preparation is preserved.

This coordinates cooperating installers only. It does not provide atomicity against arbitrary external editors that ignore the lock, and the source still uses two atomic file replacements rather than a single pairwise filesystem transaction.

### `L15-auth-download-limits`

`downloadFile` now forwards `maxBytes` and `timeoutMs` as `maxBytes` and `totalTimeoutMs` to the authenticated resumable helper. The helper validates the caller limits against the 1 GiB signed hard cap, rejects an expected asset larger than the requested byte limit, and enforces the byte limit in the stream transform while retaining checksum, signed-size, idle-timeout, and partial identity behavior.
