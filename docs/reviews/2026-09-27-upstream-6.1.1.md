# Upstream 6.1.1 and current report review

Compared NEKODEX `1d7d2ab` (the 6.1.0 mainline) with upstream `v6.1.1`
(`a13cd09`) and the upstream release, pull requests, and issues updated since
September 24. [The 6.1.0 review](2026-09-25-upstream-6.1.md) already records
the 6.0.0-to-6.1.0 interface decisions; this review checked those owners again.
NEKODEX has separate account, updater, browser, and broker lifecycles, so upstream
changes were adapted to those owners rather than copied wholesale.

| Upstream 6.1.1 area | NEKODEX decision |
| --- | --- |
| Activity replies, grouped turn markers, answer versus status text, DOM rebind | Adapted to `chatgpt-session.ts`, `browser-submission-dom.ts`, `browser-response-dom.ts`, `browser-dom-revision.ts`, and the worker. An Activity marker now establishes an assistant turn, status stays out of the final answer, and a replacement user group must match the acknowledged turn or submitted text. |
| Effort picker hydration and capability detection | Read slider range and locks in one DOM revision with a bounded hydration retry. A brief absence of the control no longer advertises a Luna-only account before the full inspection budget. Existing picker behavior without lock ticks remains supported. |
| Completed file upload controls | Accept the current native `button` attachment surface as well as the older `role=button` surface. |
| Session changes while the browser is hidden | The Electron host checks the authenticated endpoint after relevant HttpOnly cookie changes. Cookie presence alone never authenticates an account. It retires a confirmed signed-out or changed principal; the in-page probe retains Temporary Chat and full session-fingerprint authority. |
| Workspace write grants | Adapted the upstream exact grant-set comparison, including explicitly authorized output directories outside project roots and repeated grants. |
| Compaction completion and control copy | A browser response that finishes without a control handoff now fails explicitly. The reserved operation description and prompt distinguish a failed tool call from an unproven safety block. |
| ProLite Limits page and plan labels | Not imported. NEKODEX does not ship upstream's optional Pro Limits feature; its Activity screen reports local Web and Native observations with a different contract. |
| Upstream download/install and test changes | NEKODEX keeps its authenticated prerelease updater, fork identity, version policy, and its own focused verification. No upstream installer was run. |

The new model catalog advertises only named Web entries. The previous fixed-mode
slugs remain resolvable for saved tasks. Native model rows still come from the
live Codex catalog; NEKODEX does not rename them or infer account entitlement.
The direct Hermes provider now accepts every named model it advertises and defaults
new sessions to GPT-5.6 Sol; it still accepts a saved fixed-mode request. The
localized README and current setup guides were reconciled with Native6,
Zero Risk4, the named catalog, and the NEKODEX repository URL.
The source version is `6.1.1-nekodex.1`; the public README and source installer
still point to the actually published `6.1.0-nekodex.1` package until a separate
release is authorized and produced.

## Focused evidence and limits

- Root and launcher TypeScript checks, renderer build, version synchronization,
  and whitespace checks passed during adaptation.
- Captured 6.1.1 Activity layouts produced a grouped assistant identity; the
  completed capture returned `answer 1` while progress appeared as status or
  commentary, and the incomplete capture had no completion control.
- A broker call settled on a complete response frame before a delayed socket
  close. A failed contender's close left another live Unix socket in place.
- An isolated Manual turn kept its prompt copyable after Sent and cleared it only
  after connector start; the deadline refreshed on Copy.
- The Hermes catalog advertised named rows, accepted a named GPT-5.6 Sol request,
  and retained one old fixed-mode request for an existing session.
- Renderer fixture navigation covered Overview, Connections, Settings, Browser,
  Accounts, Activity, Task Center, and Updates. An injected add-account failure
  retained the draft, and retry created the account.
- The isolated Electron DEV profile launched. Its live ChatGPT page encountered
  an authentication/security challenge, so these checks do not establish a
  successful signed-in Web turn or provider-side tool result.
