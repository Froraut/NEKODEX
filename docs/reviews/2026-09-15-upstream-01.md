## Integration decision for #487

A narrow schema-aware `codex_exec` forwarding patch and one two-scenario focused test were researched in this lane, then removed before integration. The public optional fields would change both `tools/list` contracts. Their complete-schema pins belong to `Codex Native3` (`tests/chatgpt-web-harness.test.ts:2729-2740`) and `Codex Zero Risk2` (`tests/zero-risk-mcp-lifecycle.test.ts:294-300`); [architecture](../architecture.md#L73-L80) requires a new connector identity for any public schema change. Leaving the patch without that migration would produce known broken pins and cached ChatGPT connector schemas. Parent therefore deferred it as a separate coordinated compatibility change.

Final lane 1 state: no code, test, connector identity, profile, policy, dependency, tunnel, or production change. Only this triage report remains. No tests were executed. #487 is still open at the `codex_exec` convenience-wrapper level; exact generic tool invocation is already available and leaves all approval decisions with the outer Codex runtime. For #489/#449/#446, privacy-safe diagnostics remain the only justified follow-up until an authoritative refusal stage is observed.
