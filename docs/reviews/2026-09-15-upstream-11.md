## Handoff

One narrow actionable source change is justified: preserve the user-selected browser tab when an automatic turn acquires or reuses a background lease. Current capacity control already exceeds #459's fixed ten-tab proposal at the configuration/admission layers; live browser/model load remains unmeasured. The Web-only sub-agent switch and manual New chat are optional product decisions. Treat #408/#410 as one related `/goal` symptom cluster requiring a correlated failing trace before code changes.
