# Upstream 6.1.0 review

Upstream commit `293341084ac7a1ddd2de12fede3706023f5b6474` ("Release 6.1.0: support updated ChatGPT UI and hidden browser checks") follows `7579422`, the last commit covered by the [v6 review](2026-09-24-upstream-v6.md). The NEKODEX base is `6c1cdd4`.

| Upstream change | Decision |
| --- | --- |
| Updated composer, Send/Stop, grouped `data-turn-key` turns, assistant Markdown and completion controls | Adapted into NEKODEX's split modules: `chatgpt-session.ts`, `browser-submission-dom.ts`, `browser-response-dom.ts`, `browser-dom-revision.ts`, `browser-diagnostics.ts` and `browser-worker.ts`. The ProseMirror composer fallback and the legacy selectors remain. Multipart ACK detection also reads grouped assistant turns. |
| Power effort picker, `aria-labelledby` menus, locked ticks | Adapted. Pickers that omit tick attributes keep NEKODEX's modal-gate check. Pinned Pro versions open the picker's advanced view. |
| App-mention connector pills, mention list rows, `aria-current` highlight | Adapted. The mention list is accepted inside or outside a `.popover`, without counting sidebar rows. |
| Uploads through the new composer file input and attachment surface | Adapted. |
| Stop visible before the assistant node mounts | Adapted as an extension of the DOM grace only. The task deadline is unchanged. |
| Announcement dismissal on automatic surfaces | Adopted as `browser-announcements.cjs`. It is enabled when an automatic surface is marked, disabled when switching to Manual, and restored after a failed mode change. |
| Hidden primary view device emulation | Already present in NEKODEX. The duplicate lines from the merge were removed. |
| Launcher composer readiness selector | Applied to `browser-auth-probe.cjs`, matching the runtime composer selector. |
| Activity log reading by valid events | Adapted to NEKODEX's bounded log reader. The existing source-alias and atomic export protections are kept. |
| Window restoration onto the most-overlapped display | Adopted in place of the title-bar visibility check. |
| Linux update guidance | Adopted with NEKODEX naming. |
| Native tool safety sentence in the prompt | Adopted. |
| Updated connector guide video | Adopted. NEKODEX had upstream's previous file unchanged. |
| Tutorial video play/pause overlay and strings | Not needed. NEKODEX's video already uses native controls without autoplay. |
| Pro Limits settings page | Not included. NEKODEX does not ship the Limits feature (see the v6 review). |
| Windows installer latest-release redirect | Not included. NEKODEX releases are prereleases, and its installer resolves them from the release list with an asset check. |
| READMEs, TROUBLESHOOTING wording, versions and tests | NEKODEX keeps its own documents and versioning. The repository has no automated test suites. |

## Verification

Root and launcher TypeScript checks, the launcher build, `check-version` and `architecture:check` passed. A scratch script outside the repository ran `submissionDomState` and `responseDomSnapshot` in headless Chrome against upstream's `chatgpt-power-streaming.html` and `chatgpt-power-complete.html` fixtures:

- both roles of the grouped turn were identified;
- the answer contained its heading and not the user's footer;
- completion was reported only for the completed snapshot, whose text ended with its end marker.

These are captured snapshots, not a live ChatGPT account turn.
