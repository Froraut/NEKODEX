# Wave 1 implementation, lane 07 — account pool

Baseline: `3a66157`. Addressed D05 and D17 in `launcher/electron/account-pool.cjs` only. No public tool schema, account registry format, connector name, model ID, Native4/Zero Risk4 route, or ABI pin changed.

- D05: A pinned **new** automatic turn applies the existing `eligible()` readiness rule to its pinned owner. A failed check returns a pinned-account readiness error before reservation/tab acquisition; affinity remains unchanged and no other account is tried. Exact ready retained tabs, explicitly retained conversations (which retain the existing exact precheck), and already-running same-trace continuations preserve their disabled-account continuation path. Selected-mode default leniency remains the same as for unpinned eligibility.
- D17: Tab selection waits for the owning host once, checks that the original target tab still exists, and rejects an older click if account selection changed during the await. It then selects the account and tab synchronously. If descriptor/tab activation throws, it restores the prior selected account/home descriptor only while this click still owns the selection revision; a later user choice is never compensated away. Turn ownership and affinity are untouched.

Cross-lane API: **none**. Existing `selectTab(tabId)`, `selectAccount(id)`, `chooseAccount(traceId, key, retained, requirement)`, `beginTurn(...)`, and BrowserHost methods retain their signatures. `selectionRevision` is private pool state; writers of `main.cjs`, `state.cjs`, `App.tsx`, and BrowserHost need no new contract.

Verification: manual source/diff review of changed branches, direct BrowserHost `selectTab`/retained-tab semantics and registry selection, plus `git diff --check`; no tests, typechecks, benchmark, build, account interaction, install, commit, or publication. Live account readiness and a real tab-close interleaving remain unverified for the parent's shared focused pass. If the descriptor or rollback itself fails, the warning records the rollback failure and the original error still propagates.
