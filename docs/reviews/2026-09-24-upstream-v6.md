## Coverage and decision standard

66 issues. It includes all 23 open records (20 issues, 3 PRs), plus records of
either kind updated since the previous complete scan at
`2026-09-21T09:14:47.086909+00:00`. Older numbers with new comments are included.

read. A closed PR is not assumed to be merged, and an issue closure does not

setup/platform and launcher/model review; two GPT-6 Luna/high agents for issue

probes first confirmed `gpt-6-sol` and `gpt-6-luna`; no model substitution was made.
The parent owns integration, the ledger, architecture map and publication.

## Release decisions

| v6 decision | NEKODEX disposition |
| --- | --- |
| Explicit Web families and native Effort choices | Added the five named identities while retaining the original fixed Web entries and requested native-first order. Sol groups only equal context budgets; Instant and the two Pro versions stay separate. Old saved tasks retain immutable effort semantics. Selection carries an exact family through the helper and verifies the radio, slider and description before Send. |
| Optional Pro Limits tab | Reviewed but not transplanted. It is a separate opt-in estimate of messages sent through one launcher, with dated policy limits, rolling windows and incomplete external history. NEKODEX already has account-scoped Web receipts and distinct provider-reported Native quota. Those are not claimed to be equivalent to the new estimate; another counter/store and billing inspection were not necessary for the selected reliability work. |
| Six smaller Bigger Context parts | Already present in the fork's multipart contract and input policy. Preserve the measured envelope, final-part tools/attachments and existing total context budget. |
| Fresh browser chat for each turn | Already available. Added consistent ready-document retirement when committed conversation policy changes and excluded new account/turn admission during the preference transition. |
| Save chats in ChatGPT | Added default-off config, CLI/DEV setup, state, preload and Settings plumbing. Ordinary chats can apply ChatGPT memory/custom instructions; the UI discloses that. It is independent of fresh-per-turn behavior. |
| Native Linux ARM64 distribution | Reviewed, not declared supported by this fork. It needs a matching authenticated release/runner platform path and native package validation. Existing x64 libnotify/AppImage corrections were adapted without publishing binaries. |
| New upstream icon | Keep NEKODEX branding and existing identity. No upstream icon replacement. |
| Locked account efforts | Capability discovery excludes locked upsell ticks from the catalog, and submission independently rejects a locked target. Older pickers retain the existing active probe/modal checks; missing Pro controls do not become a fabricated quota diagnosis. |
| Trusted environment and continuation recovery | Adapted typed environment-fragment handling and recovery only from the current native rollout or a verified completed checkpoint. Keep existing authenticated delegation and reject conflicting authority. |
| Native `responses/memento` compaction | Added assistant-text compaction alongside remote-v2 item responses, preserving no-tools execution and exact completed-checkpoint ownership. |
| Cancellation and delivery diagnostics | Separate immediate revocation receipts from physical cleanup; lease cleanup/idleness still requires settlement. Add bounded counts/phase receipts without prompt/tool contents. |
| Browser acquisition, authentication and accepted generation | Adapted direct acquisition cancellation and ordinary authentication-probe coalescing. Preserve queue ownership and existing no-second-Send recovery after acceptance. |
| Markdown fidelity | Preserve pending link hydration and link destinations in stream consistency; escape Windows path labels. Existing plan-marker restoration stays in place. |
| Hook serialization and route ownership | Adapted the post-release TOML AST range fix while preserving JSON-hook trust helpers, exact command/hash checks and unrelated settings. A selected custom provider fails with explicit guidance instead of being overwritten. |
| Installation and updates | Added successful route-change restart guidance, exact-PID tunnel stop evidence, Windows API rate-limit guidance, Linux SONAME/ELF checks and protection against stable-looking GitHub prereleases. Preserve signed/verified fork delivery. |

parent checks integrated types, development builds, affected Settings interaction
and the generated architecture map. Passing them does not prove an installed
version, a signed release, a live ChatGPT model response or native Windows/Linux
installation. No production route, account, tunnel or installed application was
changed. Same-day external browser reports #661–#663 still need the failing DOM
and correlated live state before a specific fix can be claimed. The uncertain
