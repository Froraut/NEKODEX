- **#610:** transactionally probe Extra High rather than infer availability from the number of slider positions. Restore the original selection/menu, leave unrelated dialogs alone, preserve both primary and cleanup failures. - **#601:** read current environment across the observed native compaction-summary layouts only after matching exact canonical native rollout authority. Server-shaped item IDs alone cannot supply authority.
- **#568, new narrow adaptation:** accept a trailing pathless date/environment delta only as a same-turn policy claim; recover paths exclusively from the exact latest canonical rollout. Missing rollout, stale turn, different sandbox/network policy and supplied path authority fail closed.
- **#612 / #613 and Evan legacy formatter behavior:** tolerate semantically unchanged trust-state reordering and a removed legacy end marker while retaining unique owned definitions and foreign TOML. Preserve original separators during restoration.
- **#600:** bounded Windows-only EBUSY/EPERM retries for the exact current staged tunnel executable. Preserve the original verification failure when cleanup also fails. No broad stale-file deletion or adoption of untracked executables.
- **#614:** document that `max_threads` and `max_concurrent_threads_per_session` must not coexist as duplicate aliases.
- **Evan rolling-session idea:** optional, per-account rolling budget for newly created automatic Web sessions. Disabled by default, separate from pacing; retained work can continue subject to existing protections. No account failover. Count owned reservations, roll back proven pre-creation failures, keep snapshots read-only, and expose save/disable plus used/remaining/reset state in the UI.

## Deliberately not imported

- **#615:** mixed 91-file stack has premature delivery receipts, incomplete cumulative accounting and unsafe/unbounded completion recovery. The author's 40k message measurement is evidence for future account-aware design, not a new global limit. No new resume ledger or false completion path was introduced.

A coordinated endpoint-ownership protocol, including mixed-version behavior, is required; this report does not claim the risk fixed.
- **#589:** no debugger-based monkey patch of remote minified ChatGPT renderer code without a matching local profile and a stable contract.
- **#611 / #609:** keep the existing structural personalization fallback. Do not replace it with an unverified static translation list; no new locale-specific fix is claimed.
- **#598 / Evan #41:** browser-host-only mode and a public extension ABI need explicit lifecycle/capability designs. Hiding buttons does not prevent backend route mutations.
- **#595:** same account on multiple devices may require device-scoped connector identity. Unknown/stale tokens remain rejected; no speculative token relaxation or connector migration was added.
- **#596 / #590:** no filesystem trust by path resemblance, and no external compaction backend receiving full history.
- **Evan #42 / #43:** its chunked prompt insertion is absent locally; do not import the mechanism implicated in extra-LF corruption or weaken exact prompt readback. **#44:** retain the newer local bounded exact-surface rebind; no current local failure proves an additional patch.

- Twelve environment/compaction/date-delta cases passed, including real temporary native rollout files, missing/stale authority and network mismatch.

Its first fixture omitted the admission gate; that fixture was completed and only the failed case was rerun.

Synthetic state only; no account or provider was contacted. Its tab/server were closed.

No full repository/package suite, installer build, release tag/publication, installed-app replacement, live account mutation or native connector migration was performed in this batch. Installed 5.9.0-nekodex.1 is separate from these new source changes.
