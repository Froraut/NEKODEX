## Lifecycle policy

The #581 adaptation deliberately requires a disconnected exact observer, unchanged ownership,
no competing active conversation, and proven retirement of the broker capability before residual
cleanup after the grace interval. It does not infer abandonment from thirty minutes without a
tool result. Long commands and approval waits retain their existing ownership. Reconnection
revokes the old cleanup receipt even if it happens within the same wall-clock millisecond.

reimplemented. The fresh-conversation worker now sends connector identity only with a retained
conversation key; per-request native system-proxy lookup uses an authenticated loopback control
