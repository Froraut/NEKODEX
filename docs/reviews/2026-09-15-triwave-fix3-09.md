## Adversarial correction result

The current implementation is closed over the accepted residual helper-child
ownership path:

- Operations sharing one `descriptorPath` use one serialized tail.
- A child that survives graceful shutdown, `SIGTERM`, and `SIGKILL` remains in
  that descriptor scope's retained set until its exact `exit` or `close` event.
- A later operation in the same scope reconciles exited handles and refuses to
  spawn while a retained child is still active.
- Independent descriptor paths have independent queues and retained-child
  sets, so a slow helper for one account does not block another account.
- Scope entries are released only after queued operations and retained exact
  child handles have settled.
- Primary helper errors remain primary; cleanup errors remain attached as
  `cleanupError`, with the operation ID preserved.

I found no remaining interleaving in this file that can spawn a second helper
in the same browser scope beside an active retained child, release ownership
before the exact child has settled, or accept a mismatched connector result.
The operation allow-list, request correlation, readiness handling, stream
error handling, shutdown sequence, exports, and `verify` connector-name guard
remain intact.

## Exact residual limits

1. Retained-child ownership is process-local. If the launcher itself exits,
   this module cannot reconcile a helper child afterward.
2. A helper whose browser/Chromium teardown exceeds the bounded graceful,
   `SIGTERM`, and `SIGKILL` observation windows still produces cleanup failure;
   a successful helper result can therefore be reported as failed while the
   exact child remains retained until a later exit/close event.
3. Source review does not prove OS signal delivery, pipe behavior on every
   platform, Chromium/CDP teardown timing, account-side connector availability,
   or a completed live ChatGPT turn.
4. Descriptor-path identity is the existing caller-provided browser-scope
   contract. This file does not independently prove that two distinct browser
   hosts can never receive the same descriptor path or that one host cannot
   change its path while an operation is pending.
5. No source-level defect was found in this final lane that justifies changing
   Native4, Native4DEV, ZeroRisk4, connector schemas, exports, or ABI pins.
