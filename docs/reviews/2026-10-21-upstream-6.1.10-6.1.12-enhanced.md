## Already present in NEKODEX

- #840 / 6.1.10 shared-stdio handshake: SDK 0.0.16 and `MCP_STDIO_SEND_INITIALIZED_NOTIFICATION` on every tunnel connect path (landed with the 2026-10-16 review).
- #842 worker inventory in calendar deltas: NEKODEX's own delta parser already accepts `<subagents>`.
- 6.1.10 expansion of collapsed Bigger Context stages and 6.1.11 Activity handoff expansion: NEKODEX matches stages by their acknowledgement text and never expands stage bodies.
- 6.1.11 saved chats by default and Verify runtime: connector checks and tool/Manual turns already use saved chats (NEKODEX #101). #864 guidance therefore has no reachable path.
- #881 auto-approval opt-in across upgrades: NEKODEX upgrades rebind the saved configuration.
- Enhanced: aborted compaction sources, failed-diagnostic retention ranking, queued native input, visualization roots and home aliases (Evan's fixture passes on NEKODEX), #98 Temporary Chat connector loss.

## Follow-up candidates (not in this change)

- #837 delegation recovery (`c1682868`, `4a9035f1`): NEKODEX skips compaction requests in `normalizeNativeDelegation`, so a dropped delegated instruction is not recovered. Needs the normalization prerequisite plus checkpoint `sourceWasDelegation`; large enough for its own change.
- #861 native compaction "missing cwd": reproduced against NEKODEX's resolver with the reported request shapes; a scoped `isNativeCompactionContinuation` plus managed date-only delta patch exists in the review scratch area. Upstream has not released its fix; compare before porting.
- #854 replacement helper taking over a running tab: NEKODEX's queued path already refuses it (with a misleading message); the legacy direct `/v1/turn/start` path still reaches the takeover. Port as a typed `turn_owner_lost` 409.
- #867 side issue: an older NEKODEX copy rebinds the runtime to its older version on launch. A downgrade guard is a product decision because deliberate rollbacks currently work without Setup.
- 6.1.11 model-control interaction diagnostics and 6.1.12 `page_state` safe-log line: low priority diagnostics.
- Enhanced `447827d4` explicit submission identity: only if logs show detached-response user-turn conflicts on turns without a connector token.
