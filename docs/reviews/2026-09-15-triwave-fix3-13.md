## Adversarial review of accepted paths

### Account selection and failed selected-account check remain cross-scope

The final lane-12 handoff identifies two still-open state-owner paths:

- selecting account B after account-bound MCP proof was established for A;
- a failed connector check for the currently selected account.

`Overview` receives `browser.accountId` and global state flags, but
`LauncherSnapshot` does not contain the account-pool selected-account record or
its `connectorReady` value. `setupIdentityHash` is an opaque persisted value;
this component cannot compare it with the current account identity. Adding a
local predicate based only on `authenticated`, `mcpSetupComplete`, or
`accountId` would either continue to display stale proof or suppress valid
proof without evidence that the opaque identity matches. The minimum correct
fix remains in the owning `main.cjs`/account-pool publication path: invalidate
or qualify account-bound MCP proof when the selected account changes or its
selected-account connector check fails, then publish the resulting state.

### Interaction-mode transition remains cross-scope

The accepted lane-12 handoff also records Manual-to-Automatic proof reuse.
Overview cannot distinguish a Manual local verification from an Automatic
connector verification because both are represented by the same global
`mcpSetupComplete` flag and no mode-qualified proof field is exposed to the
component. The correct owner is the interaction-mode state transition in
`main.cjs`/state publication, which must retire the old proof when entering
Automatic mode while preserving Manual-mode semantics.

### Startup failure and logout presentation

The current Overview gate requires `browser.authenticated === true` for the
tool badge and for the Browser CTA. This prevents a stale global MCP flag from
being presented as current while the browser is signed out. The existing
startup-failure state writers clear current MCP proof before route recovery, and
the component consumes that current flag. No additional Overview-only change
is justified for those paths.
