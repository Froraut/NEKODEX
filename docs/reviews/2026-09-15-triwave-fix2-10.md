## Implemented correction

Fixed the accepted lane10 residual `T2-10-2`: compensation could restore an unguarded journal path that the current operation had not written. In a cross-scope interleaving, an external writer could change the primary journal after `writeFilesWithCompensation()` took its snapshots but before the guarded `hooks.json` write failed. Rollback then had no ownership check for the untouched primary journal and could restore its old bytes.

The journal-owned write plans in this file now capture the exact current bytes of existing journal copies and pass them as `expectedData`:

- pending JSON-hook recovery's primary journal commit;
- v2 marker reconciliation;
- divergent-copy repair.

The shared compensation helper therefore rejects a journal edit that appeared after the local byte capture, and its rollback preserves that external edit when the guarded hook write aborts before the journal write begins. The existing exact `hooks.json` guard, active-primary/inactive-recovery proof, and inactive-hook ownership rules remain unchanged.

Wave1's D07 correction remains intact: `repair: false` keeps ordinary inspection from repairing journal copies or invoking hook recovery, while explicit lifecycle recovery retains the existing opt-in path. `Native4`, `Native4DEV`, `ZeroRisk4`, their public connector identities, and public ABI were not changed.
