# Native6 release readiness (5.6.0-nekodex.1)

Native6 combines synchronous tools and Native5 owned async operations with metadata-only operation
discovery. `codex_tool_status` returns operation IDs/states, never tool arguments, results, errors
or delivery IDs. Poll supplies the result and its acknowledgement capability. Async retries recover
existing guards before compaction interception; new calls receive control output without a fake
completed invocation. Native4/5 cached public schemas remain distinct and compatible.

New Automatic Full setup selects Native6; ordinary updates retain exact saved Native4/5 identities.
The visible upgrade action configures the new identity and requires a newly created ChatGPT connector
and verification. Manual transport retains the inactive Automatic identity and restores it on return.
Transiently missing account labels do not erase stored verification proof.

## Focused evidence

Four unit scenarios and one actual Electron scenario passed:
- New Full default and retained Native5/Native4 produce distinct MCP commands/configuration.
- Manual transport retains the separate Automatic identity.
- Real MCP stdio Native6 metadata recovery, payload privacy, ownership, explicit ack and legacy schema isolation.
- Async retry identity survives compaction; new post-compaction starts return control only.
- Actual isolated Electron DEV app displays the Native6 recommendation outside advanced settings,
  opens the unverified setup wizard and reports the Native6 DEV default without claiming verification.

Root and renderer TypeScript, development helper, final Vite renderer and version consistency passed.
Total timed automated development verification: 22.852 seconds, including corrected failed attempts.
Failures corrected: incomplete configuration fixtures, temporary UI-runner syntax, missing CommonJS
export dependency, and an unnecessarily disabled navigation-only setup action. No full suite or mass
replay. Vite retains its advisory about the main chunk exceeding 500 kB.

Two implementation agents and two Sol medium counter-review agents worked on disjoint bounded scopes.
Counter-review found and resolved unseen-result acknowledgement via status, Manual identity loss,
and premature proof invalidation. Agents ran no tests/builds. DEV processes were closed after the run.

## Delivery and limits

At development readiness the installed app was still 5.3.0-nekodex.1 / Native4; no live account or
route was modified. Release publication, installed replacement and actual ChatGPT Native6 selection
are separate outcomes, to be reported after delivery. Operations remain process-local with a bounded
64-operation guard history per live turn; cancellation after dispatch stops observation only.
Native6 does not enable automatic approvals or change Codex workspace permissions.

Account quotas, quick Codex login and upstream review-checkpoint skill are explicitly subsequent work.
