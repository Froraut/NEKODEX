The active guidance now names `Codex Native4` (Automatic Full), `Codex Native4 DEV` (isolated DEV Full), and `Codex Zero Risk4` (Manual) for runtimes built from the `.2` source contract. It explicitly retains `Codex Native3`, `Codex Native3 DEV`, and `Codex Zero Risk2` for the immutable published `5.2.0-nekodex.1` binary. `Codex Zero Risk3` was never published here and is not user guidance for either runtime; the parent may retain it only as a defensive configuration alias. The transition steps require starting the new runtime, connecting the relevant mode's harness, creating a new exact-name ChatGPT connector on the matching account and Tunnel with Authentication: None, then verifying Automatic Full or selecting Manual before sending. Older connectors remain unchanged because ChatGPT caches public schemas by connector identity. The guides distinguish local setup/visibility from a real tool call and make no live account or tunnel setup claim.
