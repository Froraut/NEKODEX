- dismisses the current ChatGPT overlay through the existing bounded Escape path;
- resolves the active composer again;
- clears its full contents, including any partial mention or connector pill;
- waits for the existing UI settle interval;
- verifies that the active composer is empty and that the configured connector is not selected;
- fails through the existing persistent-browser-state error path if cleanup cannot prove those conditions.

The added cleanup does not turn an alternate row, an empty observation, a stale catalog, or a cleanup failure into connector success. The catalog-refresh branch still throws its dedicated stale-catalog error before this cleanup when its existing refresh conditions are met; the refresh caller owns the page reload and rebuild.
