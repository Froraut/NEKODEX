# NEKODEX

## Режим Native6

Новая установка Automatic Full по умолчанию использует **Codex Native6**. В одном
коннекторе собраны обычные инструменты, длительные операции start/poll/cancel/ack
и новый `codex_tool_status`: он восстанавливает список операций после потери
контекста, не повторяя внешние действия и не раскрывая их аргументы или результаты.

Существующие Native4/5 сохраняют свою идентичность при обновлении приложения.
Для перехода используйте видимую кнопку Native6, создайте **новый** коннектор
ChatGPT с точным указанным именем и затем выполните проверку. Переименование
старого коннектора не обновляет его кэшированную схему. Native4 остаётся вариантом
совместимости; Manual Zero Risk4 не меняется.

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · Русский

NEKODEX объединяет отдельные профили ChatGPT, встроенный браузер, подключение моделей к Codex,
локальные инструменты MCP и диагностику задач. Это независимый форк
[codex-chatgpt-web](https://github.com/miuuyy/codex-chatgpt-web), а не официальный клиент OpenAI.

## Начало работы

1. Перенесите приложение из DMG в «Программы» и запустите NEKODEX.
2. Выберите русский язык в настройках. Войдите в ChatGPT через предусмотренный приложением процесс.
3. Установите модели в Codex. Это действие меняет управляемый маршрут Codex; одновременно им должен
   владеть только один launcher или внешний маршрутизатор.
4. Для Full harness подключите MCP и создайте коннектор с точным именем, показанным приложением.
   Следуйте инструкции выбранного режима: у автоматического и ручного режимов разные идентификаторы.
5. Перезапустите Codex, выберите именованную Web-модель и начните задачу. Новые записи —
   **GPT-5.6 Sol (Web)**, **GPT-5.6 Sol Instant (Web)**, **GPT-5.6 Pro (Web)**,
   **GPT-6 Pro (Web)** или **GPT-5.6 Luna (Web)** в зависимости от аккаунта.
   Старые фиксированные ID остаются доступны сохранённым задачам, но не показываются для нового выбора.

В автоматическом режиме NEKODEX работает с интерфейсом ChatGPT и отправляет подготовленные сообщения.
В ручном режиме вы сами вставляете сообщение, выбираете модель и коннектор, отправляете его и
подтверждаете отправку. Если ChatGPT отклонил сообщение, выберите другую доступную модель и снова
скопируйте подготовленный запрос. Нажимайте «Отправлено» лишь после принятия сообщения ChatGPT.
Название Zero Risk не означает отсутствия рисков использования сервиса.

## Возможности

Страница **Activity** разделяет наблюдаемые отчёты Web и Native: аккаунты, дни без запросов,
результаты, длительность, токены с указанием полноты данных и CSV без приватного содержимого.
Неизвестные значения не подменяются нулями; местные счётчики не являются официальной квотой.

Для длительных инструментов автоматический Full-режим по умолчанию использует **Native6**
с операциями start/poll/cancel/ack и восстановлением списка операций. Создавайте новый
**Codex Native6** (для DEV — **Codex Native6 DEV**) с именем, указанным приложением.
Native4/5 сохраняются только как совместимость для существующих настроек. После отправки
отмена может прекратить наблюдение, но не отменить уже выполненное внешнее действие.

- Отдельные аккаунты, сохранение принадлежности задачи аккаунту, настройки proxy и темпа запросов.
- Явный выбор Pro-версии и отдельной модели для автоматического резюме контекста.
- Экспериментальная передача больших контекстов в двух или шести частях с прежним общим пределом ×3.
  Увеличение числа частей не увеличивает возможности самой модели.
- Выбранные skills как текстовые вложения; содержимое вложений учитывается в контексте.
- Статистика принятых сообщений и результатов, накопительные итоги и восстановление локальной истории.
  Это наблюдаемые счётчики, а не официальные квоты аккаунта.
- Причины ошибок каталога, диагностика маршрута и экспорт журналов без содержимого запросов.

Ограничения сервиса, доступность моделей и внешние ошибки ChatGPT не устраняются самим launcher.
Повторная установка моделей не исправляет ошибки браузерного ответа или исчерпанную квоту.
Сначала прочитайте [руководство по диагностике](TROUBLESHOOTING.md).

## Разработка

Проект использует закреплённый Bun 1.4.0. Команды установки зависимостей и изолированного запуска
описаны в [основном README](README.md#develop). Не используйте production-профиль для
экспериментальных запусков и не копируйте в них cookies или ключи.
